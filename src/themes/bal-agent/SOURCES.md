## 采集方式与污染排除

- 用本机 Chrome（Playwright，1600×1000、deviceScaleFactor 2）打开 Figma 只读链接，通过缩放菜单与画布拖拽定位到 50% / 100%，逐屏截图。
- 50% 缩放 + 2 倍像素密度时，1 设计像素 = 1 截图像素，便于量测。
- 已排除：Figma 编辑器外壳（顶栏、工具栏、缩放菜单）、Cookie 与注册提示条、画布空白区域。
- 色值优先取设计稿中印出的变量值，并用截图取色复核；两者冲突时以取色结果为准并单列冲突。

## 来源缺口与冲突

| 项 | 情况 | 处理 |
| --- | --- | --- |
| 品牌主色 | 设计稿说明文字写「品牌 #2555EB」，但品牌色块与页头实取为 `#2563EB` | 主题采用 `#2563EB`，冲突保留待确认 |
| 成功色 5 级 | 设计稿只给 3 值（`#24B47E / #168560 / #EAF7F0`），无 hover/pressed | 只落地 3 值，不做 5 级推导 |
| 间距标尺 | 规范页未提供间距页 | 按 4px 基准保守默认，标注 `合理推断` |
| 圆角 | 规范页未逐项标注圆角数值 | 按截图量测给出控制件 / 卡片 / 标签三档，标注 `合理推断` |
| 阴影 | 规范页未提供阴影层级；界面呈扁平卡片风格 | 只给一档轻浮层阴影，标注 `合理推断` |
| 响应式 | 设计稿为固定桌面画板，无断点说明 | 断点与折叠策略标注 `待用户确认` |
| 动效 | 规范页未提供时长与缓动 | 保守默认 0.2s / 0.25s，标注 `合理推断` |
| focus / hover 细节 | 按钮页有「悬停 / 聚焦 / 加载」示例态，但未给色值 | 状态色按品牌色明暗推导，标注 `合理推断` |
| 输入框 / 复选框细节 | `05` 小节部分内容被折叠 | 只登记可见部分，尺寸与状态标注 `待用户确认` |
| Figma 结构化数据 | 无 Figma MCP，未读取 Variables / Styles / Auto Layout | 已在来源表登记为部分完成 |
