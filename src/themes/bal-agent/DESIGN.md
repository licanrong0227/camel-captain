# BAL-agent 设计系统（bal-agent）

来源：Figma `BAL-agent` / `00 - BAL Design System` / `01 - 共用基础组件`（`src-001`）
采集日期：2026-10-31
采集方式：游客态只读打开设计稿，50% 缩放逐屏截图 + 截图取色复核（`src-002`）。结构化 Figma Variables / Styles 未采集。

## 1. 视觉主题与氛围

- 产品背景：BAL-agent 是出海达人营销的 AI Agent 中后台，覆盖建联、议价、寄样、内容审核、结算与素材生产。界面以「Agent 替你推进到下一步」为叙事主线。
- 关键词：克制、可信、任务导向、浅色工作台、数据可读。
- 页面气质：大留白 + 白色卡片 + 极浅灰画布；蓝色只出现在主行动、当前状态与链接上；业务状态用「浅底 + 深字 + 小圆点」表达，不用大面积饱和色块。
- 信息密度：中高。单卡 2–6 行信息，卡片之间靠 24px 间距分组，不靠重分割线。
- 品牌表达边界：AI 能力（解析产品、生成 Brief、AI 修改）用固定渐变区分；普通业务状态不得使用渐变。深色只出现在 `02 各 Agent 业务组件` 的章节头，不作为页面主色。
- 适用：Agent 工作台、任务跟进列表、审核与议价流程、素材与商品信息表单。
- 不适用：对外营销落地页、深色主题客户端、需要强品牌装饰的展示页。

## 2. 色彩系统

### 2.1 品牌与语义色（`src-001` 01 色彩）

| Token | 值 | 语义角色 | 使用边界 |
| --- | --- | --- | --- |
| `color/brand` | `#2563EB` | 主按钮、链接、选中、进行中 | 只用于主行动与当前状态；不做正文色 |
| `color/actionText` | `#1E40AF` | 行动文字（深一档） | 浅蓝底上的强调文字、渐变按钮文字 |
| `color/brandSoft` | `#EDF4FF` | 品牌浅底 | 选中行、浅底按钮、提示条底色 |

> 冲突：设计稿说明文字写作「品牌 #2555EB」，品牌色块与页头实取为 `#2563EB`。本主题采用色块实取值 `#2563EB`，冲突待用户确认。

| 组 | 常规 | 深色文字 | 浅底 |
| --- | --- | --- | --- |
| 成功 `success` | `#24B47E` | `#168560` | `#EAF7F0` |
| 警示 `warning` | `#F5A623` | `#B76E12` | `#FDF2DE` |
| 错误 `danger` | `#F04452` | `#D92D43` | `#FFF0F2` |

- 语义：成功 = 已完成 / 已合作 / 通过与签收；警示 = 待处理、暂缓与需要留意；错误 = 失败、校验错误、紧急待办标记。
- 深色小字一律使用同组「深色文字」，不得把常规色当文字色使用。
- 设计稿只给三组功能色各 3 个值，没有 hover / pressed 级；本主题不推导额外色阶。

### 2.3 合作阶段识别色（Tag / 圆点 / 进度）

| 阶段 | 前景 | 浅底 |
| --- | --- | --- |
| 待回复 | `#2563EB`（推断，取品牌色） | `#E7EFFF` |
| 议价中 | `#8B5CF6` | `#F1EBFE` |
| 待寄样 | `#0ABCD8` | `#E1F2F6` |
| 物流追踪 | `#F5A623` | `#FDF2DE` |
| 待审核 | `#4F46E5` | `#EAE9FC` |

| 待结算 | `#24B47E` | `#EAF7F0` |

- 阶段色只用于 Tag、圆点、进度条，不用于按钮。
- 进度条：灰色 = 待回复；蓝色 = 已回复部分；绿色 = 已合作部分。人数口径按页面数据保留。

### 2.4 渐变（Paint Style）

| 样式名 | 色带 | 使用场景 |
| --- | --- | --- |
| `BAL / AI / Flow Gradient` | `#3F71FE → #6D65F9 → #B95BDA → #FE9D49 → #FFB24C` | 解析产品、生成合作 Brief 等 AI 主行动 |
| `BAL / AI / Edit Gradient` | `#4291FF → #AB6FFF → #F79160` | 邮件与文案中的 AI 修改 |

- 渐变只服务 AI 能力；与业务状态色严格分开。
- 浅蓝「起草建议回复」不走渐变，复用 `color/brandSoft`。
- 色带取自截图取色，起止与中间色可靠；精确 stop 位置未标注，标注 `合理推断`。

### 2.5 禁用项

- 不用品牌蓝做正文文字或大面积页面底色。
- 不用渐变表达业务状态（已完成 / 待审核等）。
- 不用紫、粉等阶段色做按钮主色。
- 不用纯黑 `#000` 做正文，正文固定 `#1D2129`。

## 3. 字体系统

- 字族：`PingFang SC`；回退 `-apple-system, BlinkMacSystemFont, "Segoe UI", "Hiragino Sans GB", "Microsoft YaHei", Helvetica, Arial, sans-serif`。
- 设计稿原文：「PingFang SC 贯穿标题、正文、操作与数据；示例保留真实字号。」「新增数字使用 Regular / Medium / Semibold。」

| 级别 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 关键数据 | 30 / 38 | Semibold 600 | 金额、人数、核心指标 |
| 页面标题 | 28 / 40 | Semibold 600 | 页面级标题 |
| 模块标题 | 18 / 28 | Semibold 600 | 区块、流程阶段标题 |
| 卡片标题 | 16 / 24 | Medium 500 | 卡片头、弹窗标题 |
| 正文强调 / 操作 | 14 / 22 | Medium 500 | 按钮、表格重点列、可点文字 |
| 正文 | 14 / 22 | Regular 400 | 常规内容 |
| 辅助说明 | 12 / 20 | Regular 400 | 时间、备注、次要标签 |

- 金额、人数、单号、比例等数字列使用 `font-variant-numeric: tabular-nums`。
- 中文不缩小字号硬折行；换行与截断按实际容器处理。
- 颜色与字号解耦：语义色通过 CSS 变量声明，不在排版层级里写死颜色。

## 4. 组件规范

### 4.2 Tag / 状态标记

- 结构：浅底圆角胶囊 + 8px 圆点 + 12/20 文字。
- 底色取阶段色浅底，文字取同组前景色；不使用描边。
- 同一页面内阶段顺序固定：待回复 → 议价中 → 待寄样 → 物流追踪 → 待审核 → 待发布 → 待结算。

### 4.3 输入与选择（`src-001` 05 输入与选择）

- 输入框：白底、1px `#EBEBF0`、圆角 8、高 40（推断）、14/22 文字、占位 `#687384`。
- 搜索框：左侧 16px 放大镜图标，占位「搜索任务名称、产品或关键词」。
- 单选 / 复选框：选中使用 `#2563EB`（品牌色），选项卡片为浅色块 + 选中描边 `#2563EB`（推断）。
- 视图切换：列表 / 网格两个图标按钮，选中态浅蓝底 `#EDF4FF`。
- 表单校验：错误文案 `#D92D43`，输入框描边 `#F04452`。

### 4.4 Icon（`src-001` 03 图标与资产）

- 图标库：Lucide，线性风格，`stroke-width` 默认 1.5–2。
- 尺寸三档：16 / 20 / 24；16 用于行内与表格，20 用于导航与卡片头，24 用于空态与强调。
- 平台 logo、国旗、品牌标识沿用自身配色，不套单色。
- 图标默认色 `#687384`，激活 `#2563EB`，禁用 `#B9C0CC`（推断）。

### 4.5 Navigation（`src-001` 06 导航）

- 顶栏高度 52px，白底、下边框 1px `#EBEBF0`。
- 左侧品牌 + 折叠按钮，右侧通知、帮助、账号入口。
- 侧边导航白底，选中项浅蓝底 `#EDF4FF` + 深蓝文字 `#1E40AF`，左侧 3px 品牌指示条（推断）。
- 折叠与方向图标复用基础图标，不单独绘制。

### 4.6 Card / 面板

- 白底、圆角 12、1px `#EBEBF0`、无投影；卡片间距 24。
- 卡片头：标题 16/24 Medium + 右上「收起 / 展开」操作（12/20）。
- 卡片内数据块（如报价单）用一层浅底 `#F6F7F9` 区分，不再加描边。

## 5. 布局与间距

- 设计画板按桌面宽度设计，正文容器约 1440。
- 间距基准 4px：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40（规范页未提供间距页，标注 `合理推断`）。
- 常用：卡片内边距 20–24；卡片之间 24；区块标题与内容 12–16；图标与文字 8；表单行距 16。
- 页面级：内容区左右留白 24–32，顶部 24。
- 三列卡片网格用于业务概览；过程卡片多为两列或单列全宽。

## 6. 深度、阴影与边框

- 边框：统一 1px 实线，颜色 `#EBEBF0`；分割线与边框同色。
- 阴影：规范页未提供阴影层级，界面整体偏扁平。本主题只定义一档浮层阴影 `0 8px 24px rgba(29, 33, 41, 0.08)`（`合理推断`），用于下拉、弹窗、气泡。
- 卡片不使用阴影；层级靠底色差（`#F6F7F9` 画布 vs `#FFFFFF` 卡片）+ 1px 边框表达。
- 遮罩：弹窗 `rgba(29, 33, 41, 0.4)`（推断）。

## 7. 动效

- 规范页未提供动效说明，按保守默认（`合理推断`）：
  - 颜色 / 背景过渡 `0.2s ease-out`
  - 展开、收起 `0.24s cubic-bezier(0.2, 0, 0, 1)`
  - 浮层出现 `0.2s ease-out`，遮罩淡入同时进行
- 不使用弹跳、缩放强调、视差等装饰动效。
- 加载态用旋转指示，不用骨架屏闪烁动画（规范无相关示例）。

## 8. 响应式行为

- 设计稿为固定桌面画板，未提供断点与折叠规则，以下为保守默认（标 `待用户确认`）：
  - ≥1440：三列卡片网格，侧边导航展开。
  - 1280–1440：三列降为两列，卡片内操作换行。
  - <1280：单列，侧边导航收为图标态，表格允许横向滚动。
- 表格与卡片不压缩字号；空间不足优先换行或横向滚动。
- 手机端不在本期范围。

## 9. Prompt guide

生成 BAL-agent 界面时：

1. 页面底 `#F6F7F9`，内容放白色卡片（圆角 12、1px `#EBEBF0`、无阴影），卡片间距 24。
2. 主行动用 `#2563EB` 实心按钮（高 40 或 32、圆角 8、白字）；次要动作同尺寸白底描边。
3. 业务状态一律「浅底 + 深字 + 小圆点」Tag，按 2.3 的阶段色取值，不用渐变、不用描边。
4. AI 能力入口使用固定渐变按钮（Flow / Edit），渐变不用于其他任何元素。
5. 文本只用 `#1D2129` / `#687384` 两级；数字列加 `tabular-nums`。
6. 布局优先「卡片分区 + 24px 间距」，不要用重分割线或彩色容器区分区域。

禁止：

- 不要用设计稿说明文字里的 `#2555EB` 替代色块实取值 `#2563EB`（冲突未确认前以 `#2563EB` 为准）。
- 不要把阶段色用于按钮或页面底色。
- 不要给卡片加投影、渐变、玻璃拟态或彩色描边。
- 不要自造第 4 组功能色或给功能色推导 5 级色板。
- 不要把 30/38、28/40 等字号外推到更大尺寸做「展示级」。
