## 1. 视觉主题与氛围

**产品背景**：骆驼队长跨境 ERP 系统（商品、交易、采购、物流、报表、系统、工具箱、即时咨询等模块）的中后台工作台，用户为跨境卖家的运营与采购人员，长时间、高密度、键盘与鼠标混合操作。

**关键词**：橙品牌 · 浅色工作台 · 高密度表格 · 克制装饰 · 状态可辨

- **色彩氛围**：亮色系。白色工作表面 + 中性灰阶文本，品牌橙 `#FF7D29` 只用于「需要用户注意或行动」的位置。
- **布局风格**：紧凑密集的中后台栅格，卡片式分区，表格优先。
- **装饰特征**：无渐变、无毛玻璃、无插画化装饰；层级靠 1px 边框、浅灰填充和两档阴影表达。
- **组件风格**：小圆角（控件 4px）、1px 实线边框、面性单色图标。
- **明暗氛围**：整体亮色；导航为白底浅色导航，激活项用品牌橙 + 浅橙底（`src-002` 导航页；与线上深色导航冲突已记录在 `SOURCES.md`）。

**适用场景**：ERP 业务页面、列表/筛选/批量操作、表单与弹窗、数据看板、侧边导航工作台。

**不适用场景**：营销落地页、面向消费者的品牌站、大屏可视化、移动端 App 界面（本规范未提供移动断点）。

**品牌表达边界**：品牌橙不得用作大面积页面底色；一个视图内的主色行动点（CTA）不超过 1 个主按钮 + 1 组文字按钮。

**设计原则**

1. 状态优先于装饰：颜色首先表达可点击、已选中、成功/警告/错误，其次才是品牌。
2. 五色一套规则：品牌/成功/警告/错误/信息统一使用 `-1 背景 / -2 边框 / -3 悬停 / -4 常规 / -5 点击` 五级，任何新色板沿用该结构。
3. 文本层级由中性色决定，不由字号决定：主要 `#1D2129` / 次要 `#4E5969` / 辅助 `#86909C` / 禁用 `#C0C5CF`。
4. 圆角克制：控件 4px，卡片/浮层 8px，标签 12px，全圆角仅用于头像与圆形按钮。
5. 未采集到的规则不臆造：缺失项按保守默认实现，并在需求确认时回到设计稿校准。

## 3. 字体系统

**字体族**：规范原文「优先使用系统默认的界面字体」，因此不引入 Web Font。

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", Helvetica, Arial, sans-serif;
```

数字、SKU、金额、时间等对齐场景使用等宽数字：`font-variant-numeric: tabular-nums;`

### 3.1 字号与行高（`src-002` Font 页原文，公式 `h = f + 8n`）

| 字号 | 行高(n=1) | 推荐字重 | 语义角色 |
| --- | --- | --- | --- |
| 12px | 20px | 400 | 表格正文、辅助说明、标签文字 |
| 14px | 22px | 400 / 500 | **界面基准**：正文、按钮、输入框、菜单 |
| 16px | 24px | 500 | 区块标题、弹窗标题 |
| 18px | 26px | 500 | 页面标题 |
| 20px | 28px | 500 | 一级标题 / 关键指标 |
| 24px | 32px | 500 | 数据大屏级数字、模块主标题 |
| 30px / 38px / 46px / 56px | 38 / 46 / 54 / 64px | 500 | 登录页与空态等展示级，业务页面内不进入该区间 |

### 3.2 字重（规范原文）

- `400 regular`、`500 medium` 为常规两档。
- `600 semibold` 仅用于极少数场景或英文文本加粗。
- 禁止 `700` 及以上（规范页未出现，属超出品牌表达）。

### 3.3 字体规范

| 级别 | 规则 |
| --- | --- |
| ✅ 推荐 | 业务页面字号只在 12 / 14 / 16 / 18 / 20 之间取值 |
| ✅ 推荐 | 行高按 `h = f + 8n` 取表内配对值 |
| ✅ 推荐 | 数字列使用 `tabular-nums` 保证纵向对齐 |
| 🚫 禁止 | 引入自定义 Web Font 或改变系统字体族顺序 |
| 🚫 禁止 | 使用 600 以上字重、正文字号小于 12px |
| 🚫 禁止 | 用字号区分信息层级而忽略中性色文本层级 |

## 4. 组件规范

| 状态 | 品牌 | 信息 | 成功 | 警告 | 错误 |

其他按钮形态（规范页可见）：

- **次要/默认按钮**：白底 + `1px solid #E5E6EB` + 文字 `#1D2129`；hover 边框转 `#C0C5CF`（保守默认）。
- **浅底主按钮**：底 `#FFEFE5` + 边框 `#FFD9BF` + 文字 `#FF7D29`（规范页「查询」浅底态）。

- **块级按钮**：撑满容器（登录），不改圆角与字重。

| 级别 | 规则 |
| --- | --- |
| ✅ 推荐 | 一个视图内主按钮（实心品牌橙）只承担一个主行动 |
| ✅ 推荐 | 取消/次要用白底描边，危险操作用错误色板且与主按钮分离摆放 |
| 🚫 禁止 | 主按钮使用渐变、阴影或超过 4px 圆角 |
| 🚫 禁止 | 用改变圆角或字号的方式表达按钮禁用，禁用只走色板切换 |

## 5. 布局与间距

> 未提供间距/布局规范页，本段除标注项外为**保守默认**，落地时以设计稿校准。

- 栅格：1440 设计宽度下 24 列，列间距 16px（保守默认）。
- 页面容器：内容区左右内边距 20px，页面底 `#F7F8FA`，卡片白底。
- 卡片：内边距 20px，卡片间垂直间距 16px，圆角 8px，边框 `1px solid #E5E6EB`。
- 区块标题与内容间距 16px；表单行间距 16px；表单项标签与控件间距 8px。
- 图标与文字间距 4px 或 8px。
- 间距标尺（4px 基准）：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px。
- 已确认的例外：**弹窗内容填充区 30px**（规范页原文，是唯一有来源的页面级留白值）。

| 级别 | 规则 |
| --- | --- |
| ✅ 推荐 | 只用标尺内的 4 的倍数间距 |
| ✅ 推荐 | 同级元素间距保持一致，跨区块用 16 / 20 / 24 递进 |
| 🚫 禁止 | 使用 5px、7px、13px 等未定义值 |
| 🚫 禁止 | 用加大留白的方式解决信息密度问题（应改为分表或分组） |

## 6. 深度、阴影与边框

**阴影两档**（`src-002` 阴影页只命名未标注数值，以下为量测推断）：

| Token | 值 | 用途 |
| --- | --- | --- |
| `shadow-light`（较轻阴影） | `0 2px 8px rgba(0,0,0,0.06)` | 卡片、Toast、下拉面板、悬浮元素 |
| `shadow-base`（基础阴影） | `0 4px 24px rgba(0,0,0,0.10)` | 弹窗、抽屉、浮层容器 |

量测依据：阴影页卡片下方灰度衰减约 24px，边缘最深实测 `#E8E8E8`（≈10% 黑）。

**边框**

- 统一 `1px solid`；控件默认边框 `#E5E6EB`（中性色-4），分割线 `#EBEEF5`（中性色-3）。
- 选中/激活边框使用色板 `-2`（浅）或 `-4`（强调），如 `#FFD9BF`、`#FF7D29`。
- 表格外框与内线 `#E5E6EB`（实测）。

**表面叠放**

| 层级 | 表面 |
| --- | --- |
| 0 | 页面底 `#F7F8FA` |
| 1 | 卡片/表格/导航 `#FFFFFF` + 1px 边框 |
| 2 | 下拉、气泡、Toast：`shadow-light` |
| 3 | 弹窗、抽屉：遮罩 `rgba(0,0,0,0.6)` + `shadow-base` |

| 级别 | 规则 |
| --- | --- |
| ✅ 推荐 | 先尝试用边框和浅底色差分层，再考虑阴影 |
| ⚠️ 允许 | 表格吸顶、悬浮工具条使用 `shadow-light` |
| 🚫 禁止 | 彩色阴影、内阴影、多层叠加阴影、模糊半径大于 24px |
| 🚫 禁止 | 给主按钮、标签、图标加阴影制造「可点击感」 |

## 7. 动效

> 规范页未提供动效页，本段为**保守默认**（参考 `src-003` 线上过渡值），待设计稿校准。

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| hover / active 颜色切换 | 0.2s | `ease-in-out` |
| 输入框/下拉展开收起 | 0.25s | `cubic-bezier(0.645, 0.045, 0.355, 1)` |
| 弹窗、抽屉出现 | 0.3s | `ease-out` |
| 侧边栏折叠展开 | 0.3s | `cubic-bezier(0.645, 0.045, 0.355, 1)` |
| Toast 出现/消失 | 0.3s | `ease-out` / `ease-in` |

- 只动 `opacity`、`transform`（位移、缩放），不改 `width/height/margin` 造成重排。
- 加载中图标使用匀速旋转（`linear`），这是规范页唯一出现的动效证据。
- 禁止：视差滚动、页面级入场动画串联、超过 0.5s 的交互反馈、循环装饰动画。
- 尊重 `prefers-reduced-motion: reduce`：关闭位移，仅保留透明度变化。

## 8. 响应式行为

> 规范页未提供断点定义，本段为**保守默认**（中后台桌面优先），待设计稿校准。

- 设计基准宽度 1440px（各规范页导出宽度）。
- 断点：`<1280` 紧凑、`1280–1600` 默认、`>1600` 宽松；`<1200` 时侧边栏自动收为「收起」态（导航页已提供收起/展开两态，是唯一的响应式证据）。
- 表格：列数随视口增减，操作列固定右侧，表头吸顶；不允许整表横向滚动时丢失主键列。
- 筛选区：控件宽度按 4 的倍数栅格收缩，超出一行折叠为「展开/收起」（保守默认）。
- 弹窗：宽度按内容分档并保持水平居中，纵向超高时内容区内部滚动、底部操作区固定。
- 侧边栏收起态仅显示图标，激活指示条保留（依据导航页收起态样张）。
- 移动端与 1024px 以下未采集，不承诺适配。

## 9. Prompt guide

**推荐写法**

1. 所有颜色引用语义 token（`brand-4`、`neutral-8`、`success-1` …），不要写裸 hex。
2. 业务页面字号只在 12 / 14 / 16 / 18 / 20 中取值，并按 `h = f + 8n` 配对行高。
3. 控件圆角 4px、卡片与浮层 8px、标签 4px，禁用态统一底 `#F2F3F5` + 文字 `#C0C5CF`。
4. 状态色一律走「`-1` 底 / `-2` 边框 / `-3` 悬停 / `-4` 常规 / `-5` 点击」五级结构，成功/警告/错误/信息与品牌色同构。
5. 分层优先用 `#F7F8FA` 页面底 + 白色卡片 + 1px `#E5E6EB` 边框，阴影只用 `shadow-light` 与 `shadow-base` 两档。

**禁止写法**

1. 不要生成深色导航或深色工作台——本规范是浅色导航 + 品牌橙激活态。
2. 不要使用渐变、毛玻璃、彩色阴影、大于 24px 模糊的阴影或 600 以上字重。
3. 不要把品牌橙 `#FF7D29` 用作正文文字色或大面积底色。
4. 不要用 `#1890ff`、`#ff781f`、`#001529`、`#f5f7fa` 等 `kuacheng-bi` 线上遗留值替代本规范 token。
5. 不要为未采集到的规则（focus 态、断点、图标网格、动效时长）编造「更完整」的规范，标注为待确认即可。

**可直接复用的界面生成提示**

> 按 `src/themes/camel-captain-erp/DESIGN.md` 生成〈页面名〉：浅色工作台（页面底 `#F7F8FA` + 白卡片 + 1px `#E5E6EB` 边框），品牌橙 `#FF7D29` 只用于主行动与激活态，文本层级用中性色 `#1D2129`/`#4E5969`/`#86909C`/`#C0C5CF`，字号 12/14/16/18/20 配 `h = f + 8n` 行高，控件圆角 4px、卡片 8px，状态色使用五级色板结构，阴影只用两档。完成后逐项核对色值、字号、圆角、间距、边框、阴影是否全部来自本 DESIGN.md，并把未采集项列为待确认。
