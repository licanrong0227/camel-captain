# 设计系统任务计划

## 状态定义

- `待确认`：范围、来源或关键设计决策尚未确认。
- `待执行`：范围已确认，可以开始。
- `执行中`：当前正在采集、生成或同步。
- `待验收`：产物已完成，等待 ready 检查、视觉验收或用户确认。
- `已完成`：当前任务已经通过验收。
- `阻塞`：来源、工具、授权或依赖不足，暂时不能继续。

## 组件任务

## 执行入口

每次执行说明包含：

- 读取当前主题的 `SOURCES.md`、`PLAN.md`、`DESIGN.md` 和标准派生文件。
- 读取当前任务列出的来源证据。
- 按依赖顺序执行，并在开始、待验收和完成时更新状态。
- 新增、移除或改变组件/模板范围时同步更新本文件。
