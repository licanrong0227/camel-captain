Shopify 对接 · 店铺授权

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

当前方案

本原型按线上「骆驼队长BI」页面做高保真还原，当前包含店铺授权、我的商品、我的订单和认领中心四个子页面；页面内容以截图实测像素和线上样式变量为准，不引入新的视觉语言。

  • 原型意图：复刻 ERP 中管理多平台店铺授权关系的列表页，作为后续 Shopify 相关子页面的承载框架。
  • 使用场景：运营在「系统 / 店铺 / 店铺授权」下查看各平台店铺的授权状态与到期时间。
  • 当前表达：1912 设计宽的单页静态还原，包含顶栏、面包屑、主卡片（平台页签 / 搜索行 / 操作行 / 店铺列表 / 分页）和右侧「联系我们」浮窗。
  • 认领中心（claim-center）：还原「商品 / 商品管理 / 认领中心」列表页，即采集商品进入「我的商品」之前的认领工作台，含页签带、两行筛选、8 列商品列表、选中行展开的逐条操作条和底部批量操作栏。

本次不呈现

  • 平台页签切换，以及拼多多 / Shopify 页签下的不同列表内容。
  • 搜索、重置、店铺分组、分页按钮的真实交互与结果反馈。
  • 「新增店铺」弹窗内的填写、下拉选项展开、必填校验和提交结果（本轮按用户决策只还原外观，弹窗内控件为静态呈现，打开与关闭可用）。
  • Shopify 授权流程（OAuth 跳转或填写店铺域名 + token）与授权到期提醒。
  • 移动端/侧边栏收起等窄屏形态；本页只保证 1280 以上宽度可用，窄于 1400 时表格改为内部横向滚动。
  • 认领中心的「批量查找」「导入产品」「统一导出」弹窗与「任务处理中」浮层：源页面 DOM 中存在但处于隐藏态，无截图视觉依据，本轮不还原。
  • 认领中心筛选下拉的选项展开面板（采集源字段、认领状态、采集平台、采集日期、标签）与搜索 / 重置 / 分页的真实结果反馈。
  • 「认领商品」弹窗内的可选态与业务逻辑：店铺勾选与「全选」联动、平台切换、已选店铺计数、「直接认领 / 自动编辑」的启用条件与点击结果、店铺清单为空 / 加载中状态。截图给出的是未选店铺的禁用态，本轮按该态静态还原。

店铺授权列表字段取数口径

  • 平台ID：调用 https://{shop}/admin/api/2026-04/graphql.json，取返回的 data.shop.id；口径写在表头「平台ID」标注里。
  • 到期时间：换取 Token 时 POST https://{shop}.myshopify.com/admin/oauth/access_token 需携带 expiring=1，响应根级字段 $.expires_in（Access Token，秒）与 $.refresh_token_expires_in（Refresh Token，秒）；本列按 Refresh Token 有效期换算，Access Token 只用于后台刷新换新，口径写在表头「到期时间」标注里。

设计基底与原型特有调整

  • 采用的 DESIGN.md：src/themes/camel-captain-erp/DESIGN.md
