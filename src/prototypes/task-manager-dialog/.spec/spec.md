# 任务管理器弹窗 · 主规格

## 当前方案

- 原型意图：把认领、批量编辑、批量美图、刊登、克隆、商品同步、订单同步、数据导出等后台任务记录收进同一个任务管理弹窗，按任务类型分页签查看。
- 使用场景：运营在后台完成批量操作、同步或导出后，回到任务管理器核对每一次任务的发起时间、任务范围、执行进度、成功/失败数量和失败原因。
- 当前表达：单个 800px 居中弹窗，默认展开；标题栏内放「认领 / 批量编辑 / 批量美图 / 刊登 / 克隆 / 商品同步 / 订单同步 / 导出」八个页签；刊登页签复刻发布记录，认领/批量编辑/克隆实现任务列表与商品明细，批量美图按图片处理任务单层列表展示，商品同步/订单同步按店铺单层列表展示，导出按导出记录单层列表展示。

## 事实与输入

### 用户确认事实

- 页签范围为认领、批量编辑、批量美图、刊登、克隆、商品同步、订单同步、导出八类。
- 导出页签放在页签最后，展示导出记录：导出来源、导出数据条数、状态，状态后有操作列，导出成功的记录可直接下载。
- 刊登页签复刻现有「发布记录弹窗」的内容、字段与交互。
- 认领必须体现：认领到哪些店铺、认领进度、认领成功和失败数量；明细中能看出哪些商品成功、哪些失败及失败原因。
- 批量编辑必须体现：批量编辑进度、成功和失败数量；明细中能看出哪些商品失败、分别是哪些项目失败及原因。
- 克隆必须体现：克隆进度、哪些成功、哪些失败；明细中能看出失败原因。
- 商品同步、订单同步需要作为独立任务页签，参考线上「同步线上」与「同步店铺订单」的逻辑。
- 字段只保留必要项，不堆叠字段；后续由用户在原型的验收基础上给调整建议。
- 弹窗形态为 800px 居中弹窗，默认展开，关闭后留重开入口。
- 视觉统一到 `camel-captain-erp` 设计规范，不沿用旧原型的蓝/橙配色。

- 线上认领中心 `https://test.kuachengjing.com/commodity/claim`：认领商品弹窗支持选择平台、多选店铺、仅认领/认领并发布；重复认领会逐条返回「店铺[klyto] 已认领，不能重复认领」并进入认领异常弹窗。
- 线上我的商品 `https://test.kuachengjing.com/commodity/my-products`：批量编辑弹窗按商品基本信息、类目、属性、价格、SKU、图片视频、翻译等分组编辑；AI 克隆弹窗支持原店铺/目标店铺、主图顺序随机打乱、AI 重新生成标题；「同步线上」按店铺同步线上商品数据，逐店展示「同步完成（成功同步 N 条数据）」，支持批量同步和后台执行。
- 线上我的订单 `https://test.kuachengjing.com/trade/my-order`：「同步店铺订单」按店铺同步订单，可选时间范围、指定订单、仅同步未处理订单；单店同步完成后提示「店铺【名称】订单同步完成，本次共同步 N 条」，加载中可转后台同步。
- 线上任务接口：批量编辑、认领、克隆、订单同步都以 taskId 异步执行，轮询进度，返回总条数、已完成数、失败数、进度百分比和错误明细；批量编辑的错误明细可细分到具体编辑项目。

### 当前假设

- 任务列表按任务聚合商品；明细按「商品 × 目标店铺」拆行，同一商品在不同店铺可以一成功一失败；商品维度的成功/失败按综合结果统计，任一店铺失败即计为失败商品。
- 认领并发布任务在认领页签只呈现认领阶段的结果，发布阶段的结果仍由刊登页签承载。
- 失败原因使用线上系统的真实口径；认领失败以「该商品已经认领到店铺[店铺名]」为主，其他任务使用重复商品、标题超限、违禁词、价格低于限价等真实提示，作为演示数据。
- 商品同步指按店铺同步线上商品数据；订单同步指按店铺同步订单。后台执行会为每个店铺创建一个任务，因此列表按店铺拆行，每行即一个店铺同步任务，不再进入二级详情页。
- 订单同步的指定订单可以在行内展开查看每个订单的商品、同步结果、完成时间与失败原因。
- 平台按店铺记录，同一批任务可能包含多个平台；每行展示该店铺所属平台。
- 商品同步与订单同步不展示进度，因为同步完成前无法知道总条数/总订单数；只展示已同步数量、店铺结果与完成状态。
- 店铺结果为「同步中 / 同步完成 / 同步失败」；状态列同时展示该店铺的完成或失败时间，同步失败的店铺在失败原因列给出原因。
- 同步中店铺会展示已同步数量，不是等全部同步完才显示；完成时展示最终数量与完成时间。
- 任务取消、重试、删除等操作本轮不实现。

## 原型范围

### 本次呈现

- 弹窗标题栏：标题「任务管理」、八个页签、关闭按钮。
- 认领页签：任务列表（时间、状态查询；发起时间、认领店铺、商品数、进度、成功数量、失败数量、状态/完成时间）与商品明细（按商品 × 店铺拆行：商品信息、认领店铺、认领结果、失败原因）。
- 批量编辑页签：任务列表（时间、状态查询；发起时间、商品数、进度、成功数量、失败数量、状态/完成时间）与商品明细（商品信息、编辑结果、失败原因；失败原因带失败项目前缀）。
- 批量美图页签：按图片处理任务单层展示，一个任务只处理一个商品、只执行一种操作；列表列为发起时间、商品信息（图片、itemCode、标题）、图片数、批量美图操作、进度、完成数量、失败数量、状态；失败数量可点击，在当前行下展开失败图片卡片，卡片只展示图片缩略图与失败原因，缩略图可点击放大；卡片区右上角提供「重新处理」，点击后按失败图片新建一条同商品、同操作的执行中任务并置顶，按钮变为「已重新处理」；支持时间/状态查询与分页。
- 克隆页签：任务列表（时间、状态查询；发起时间、克隆到店铺、商品数、进度、成功数量、失败数量、状态/完成时间）与商品明细（按商品 × 店铺拆行：商品信息、克隆到店铺、克隆结果、失败原因）；克隆方式后有感叹号时，悬停展示标题与图片策略，无策略则不显示感叹号。
- 刊登页签：发布记录列表（发布进度为进度条 + 完成数/总数，状态为发布中/发布完成/部分失败）、商品发布明细（含刊登平台、刊登店铺、循环状态、循环次数、发布结果、发布失败原因、最新状态，顶部展示商品总数/发布完成/发布失败/处理中统计与进度）、循环状态/发布结果/最新状态筛选、批量复制商品编号、分页；发布失败原因仅有失败时展示，正常商品显示「-」。
- 商品同步页签：按店铺展示同步任务，列表列为发起时间、平台、同步店铺、同步数据量、同步类型、状态/完成时间、失败原因；店铺名后的感叹号悬停展示同步方式。
- 订单同步页签：按店铺展示同步任务，列表列为发起时间、平台、同步店铺、同步订单数、指定订单、同步类型、状态/完成时间、失败原因；店铺名后的感叹号悬停展示同步时间与是否仅同步未处理订单；指定订单默认显示数量，点击行内展开订单卡片，卡片内展示每个订单的同步结果与失败原因。
- 商品同步、订单同步不展示进度：同步完成前无法知道总条数/总订单数，只展示已同步数量、店铺结果和执行状态。
- 导出页签：导出记录列表，列为发起时间、导出来源、导出数据条数、状态/完成时间、操作；导出状态为导出中/导出成功/导出失败；操作列对导出成功记录提供「下载」，导出中记录下载按钮置灰，导出失败记录提供「重新导出」。
- 三个任务页签的明细均支持按结果（成功/失败/处理中）筛选；支持批量复制商品编号和分页。

### 本次不呈现

- 任务的取消、重试、删除和任务详情之外的业务跳转。
- 认领并发布任务中发布阶段的明细（由刊登页签承载）。

- 导出数据保留时长与文件过期后「下载」的处理方式。
