商品采集 · 链接 / 店铺 / 收藏夹 / 采集记录

设计基底：src/themes/camel-captain-erp/DESIGN.md。系统位置：顶部导航「商品」→「商品管理」→「商品采集」；面包屑 商品 / 商品管理 / 商品采集。单页原型，页面 id product-collection。

1. 背景与目标

  • 以测试环境 https://test.kuachengjing.com/commodity/collect 为唯一事实源，还原「商品采集」页面的完整前端交互。
  • 覆盖同一页面内的四个子页签：链接采集、店铺采集、收藏夹采集、采集记录，以及页签外层的顶栏、面包屑、商品采集 / 认领中心 / 我的商品一级页签。
  • 演示数据取自测试环境的收藏夹采集（24 条）与采集记录（982 条），采集任务在原型内本地模拟推进，不调用真实接口。

2. 页面结构

  1. 顶栏：品牌、业务导航（商品激活）、任务管理器、主题 / 设置 / 帮助、消息、VIP3、头像。
  2. 面包屑与一级页签：商品采集 / 认领中心 / 我的商品，当前页为商品采集。
  3. 子页签：链接采集、店铺采集、收藏夹采集、采集记录；右侧「下载安装浏览器插件」。
  4. 链接采集：支持采集平台（亚马逊、1688、Temu、速卖通、敦煌网、SHEIN）、批量链接输入、已导入计数、清空链接、开始采集、采集设置入口。
  5. 店铺采集：平台仅敦煌网、店铺首页链接输入、清空链接、读取店铺商品。
  6. 收藏夹采集：创建日期、来源、采集链接、采集状态、价格区间筛选；表格列为图片、标题/链接、来源、价格、销量、收藏时间、采集状态；支持勾选与分页。
  7. 采集记录：采集时间、来源、采集链接、采集状态筛选；表格列为图片、标题/链接、来源、价格、日期、采集状态、采集账号、失败原因；支持勾选与分页。
  8. 采集日志：链接采集与店铺采集共用，显示任务总数 / 成功 / 失败、清空日志与逐条任务状态。

4. 交互与状态

  • 页签切换：四个子页签在同一个一级页签卡片内切换，切换后保留各页签的数据状态。
  • 链接导入：按行解析，非空行计入「已导入 N 个任务链接」；清空链接同时清除计数与校验提示。
  • 开始采集：无链接时就地提示「请先粘贴商品链接」；有链接时按条生成日志，状态由待采集依次推进为采集中、成功或失败，成功任务同步追加到采集记录首行。
  • 重复采集询问：开始采集时若命中已采集过的链接且「重复采集」为询问，弹出重复采集弹窗，展示重复链接并选择本次处理方式（新增 / 阻止 / 覆盖）；勾选「不再提醒」后可选择以后默认处理方式，提示可在「采集设置 → 重复采集」中修改，保存后回写该设置。
  • 采集设置：「链接采集」底部通过「采集设置」入口打开独立弹窗，弹窗按系统「商品配置项」样式（橙色单选 / 开关、橙色保存），包含采集默认项（重复采集、违禁词拦截、自动翻译、采集视频、无详情补图、实时采集）以及采集每个 sku 价格，与「采集设置弹窗」原型一致，不含自动翻译引擎与采集自动生成 SKU；保存后提示「采集设置已保存」，原内联实时采集开关已移除。
  • 店铺采集：未填写店铺首页地址时提示「请输入店铺首页的链接地址」；填写后提交一条店铺读取日志并推进为成功。
  • 收藏夹 / 记录筛选：点击「查询」应用草稿条件，点击「重置」清空全部条件并回到第 1 页；来源、状态、链接关键字、日期区间、价格区间均为本地筛选。
  • 分页：支持 10 / 20 / 30 / 50 / 100 / 200 / 500 条每页、上一页 / 下一页、页码与前往指定页；切换条件后回到第 1 页。
  • 勾选：表头勾选当前页全部行，支持半选状态；切换筛选或分页后清空已选。
  • 链接：平台按钮在新窗口打开对应平台；标题 / 链接在新窗口打开采集源；日志链接同样可跳转。
  • 浏览器插件：点击「下载安装浏览器插件」打开安装说明弹窗，可取消或确认关闭。

5. 设计基底与原型特有调整

  • 严格沿用 ERP 主题：页面底 #f0f1f5，白色卡片、10px 卡片圆角、4px 控件圆角、品牌橙 #ff781f、信息蓝 #1890ff。
  • 表格行高 68px、表头 44px，状态标签为浅底描边样式；主操作「开始采集 / 读取店铺商品」使用蓝色，筛选查询使用品牌橙。
  • 右侧保留「联系我们」浮标；顶栏与一级页签沿用现有原型外壳尺寸。
