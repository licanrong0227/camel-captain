编辑产品弹窗 · 主规格

本文档描述「编辑产品弹窗」原型的当前方案。原型按线上「我的商品 → 编辑产品」弹窗（基本页签）在 1100×785 视口下的实际呈现还原，以本文件与 src/prototypes/edit-product-dialog-v2/index.tsx 为准。

1. 原型定位

  • 意图：还原商品编辑主弹窗，让商品运营在同一弹窗内切换商品、按模块维护基础信息、图片、规格、价格、销售与服务信息。
  • 承载方式：独立原型页，灰遮罩 + 视口居中弹窗，不还原「我的商品」列表背景。
  • 尺寸：弹窗 90vw × 90vh，max-width: 1440px，距视口顶部 6vh；1100×785 视口下为 990×706.5，与线上一致。

4. 数据与素材

  • 商品标题、短描、属性值、规格值、SKU 编码 / 库存 / 重量 / 实际收入等来自线上弹窗当前演示数据。
  • 商品缩略图、主图、规格图、详情图取自线上当前商品，作为演示素材；离线不依赖外部图片地址。
  • SKU 表按 5 个颜色 × 4 个 Options 生成 20 行；库存统一 999，重量 0.050，实际收入 103.27。

5. 交互说明

  • 左侧列表：点击切换当前商品；删除图标移除商品；勾选图标在「未编辑 / 已编辑」之间切换；翻页在 2 页演示数据间切换。
  • 收起列表：顶部双箭头收起左侧列表，表单区随之扩展；再次点击展开。
  • 二级菜单：点击滚动到对应模块，模块标题吸顶对齐滚动区顶部；「物流/运费信息」为禁用态。
  • 短描：新增会追加空白文本域；删除移除对应行；文本域支持手动缩放。
  • 页签：基本 / 详情 / 日志可切换；详情展示模板栏、富文本工具栏和商品详情内容；日志为空状态。
  • AI标题生成：点击主按钮触发约 2 秒的生成中状态，标题前显示 12 辐条 loading，按钮与下拉箭头一并置灰不可点。
  • AI标题生成：点击右侧下拉箭头直接弹出「指定包含关键词」浮窗，浮窗的尖角指向箭头；可填写多个用逗号分隔的关键词（0/70）；关键词为空时「生成」置灰不可点；点击「生成」即使用当前关键词并清空输入框，同时进入标题生成中状态，再次打开浮窗为空白（0/70）。
  • AI生成视频：视频区块分割线下方、视频名称上方新增「AI生成视频」按钮。点击打开 780px 弹窗，参考图按主图 5 / 站外推广图 1 / SKU 图 2 / 详情图 3 分组，最多选择 9 张；缩略图左上角序号即参考顺序，取消选中后序号顺延，选满后其余图片置灰，再点提示「参考图最多选择 9 张」。
  • AI生成视频参数：参考图下方依次为视频模板、视频时长、视频比例；视频模板可选 产品展示 / UGC 种草 / 痛点解决 / 家居场景，默认 产品展示；时长 5 / 10 / 15 秒，每个时长后的问号悬停提示单次算力消耗，算力值未确定、统一用 xx 表示；底栏「预计消耗」显示 xx 算力；比例 自适应 / 9:16 / 16:9 / 1:1 / 4:3 / 3:4 / 21:9，自适应按参考图比例生成；比例下方为「销售国家/地区」「语言」两个下拉，均有默认值：销售国家/地区默认 US(美国)，语言默认 英语；销售国家/地区可选 US(美国) / GB(英国) / DE(德国) / EU(欧洲) / JP(日本) / KR(韩国) / RU(俄罗斯) / UK(英国) / MX(墨西哥) / SEA(东南亚) / ASIA(亚洲) / LATAM(拉美) / GCC(中东) / CN(中国)，国家显示对应国旗、地区显示地球图标；语言可选 中文 / 英语 / 印尼语 / 日语 / 韩语 / 法语 / 西班牙语 / 德语 / 葡萄牙语 / 意大利语 / 俄语 / 泰语 / 越南语 / 马来语 / 荷兰语 / 波兰语 / 瑞典语 / 土耳其语；未选参考图时「生成视频」置灰。接口采用 LinkFox 图生视频 v3，模型 MiniMax H3，输出分辨率固定 768P，请求参数为参考图、时长、比例。
  • AI生成视频状态：提交后弹窗切换为 520px「视频生成中」页面（12 辐条 spinner + 时长/比例/参考图张数 + 关闭不影响生成）；关闭后视频上传位保持「AI 生成中」，显示 spinner、参数、停止生成和不定长进度条；入口按钮在生成中置灰并提示「视频生成中，暂不可再次生成」。演示中提交约 4 秒后切换为「视频生成失败」：生成中弹窗显示失败页，视频位显示失败卡片，两处均提供「重新生成」，并可「取消生成」清除失败状态、回到「上传视频」。
  • 停止生成：生成中弹窗底部与视频位上的「停止生成」点击后直接结束本次生成，不再二次确认；随后视频位回到「上传视频」，入口恢复可点；关闭弹窗不会中断生成。
  • AI关键词生成：点击按钮直接触发约 2 秒生成中状态，文字前显示 loading、按钮置灰；不再提供指定包含关键词浮窗。
  • AI短描生成：参照 AI标题生成，下拉弹出「指定包含关键词」浮窗，输入上限 150 字；空值时生成置灰，点击生成清空输入并进入约 2 秒的生成中状态，主按钮 loading 置灰。
  • 保存：显示「保存成功」；保存并发布：显示「已保存并发布」；关闭：进入弹窗关闭态，可重新打开。

6. 商品合规检测

刊登前检测。检测项、状态语义、结果结构与单项重检逻辑沿用 dhgate-compliance-check，展示层按 ERP 场景收敛：同一项可有多条错误，逐条给出原因、原文或原图与建议；不展示规则库片段。

区域内容说明
入口页脚右侧「商品合规检测」分裂按钮 + 右侧下拉箭头与居中的关闭 / 保存 / 保存并发布同一行，单独靠右并用浅橙描边区分；标题后的问号悬停提示「单个商品检测消耗 xx 算力」
检测项材质、尺码、知识产权、类目、价格、违法违规名称、检测对象与结论文案沿用敦煌原型 ITEM_DEFS / PASS
检测点击主按钮 → 按钮转圈约 1.5 秒 → 弹出结果弹窗不做逐项时间轴，期间不出现中间态；检测中可关闭弹窗，后台不中断；提交前按「保存并发布」的同一套规则校验，必填项全部通过才允许检测（原型未模拟）
结果弹窗宽 720，居中；头部（仅标题与关闭）、结论条、6 个检测项、底部关闭头部与底部固定，结论条与检测项一起滚动；X / 遮罩 / Esc 关闭
检测项卡片名称 + 状态标签 + 错误计数 + 重新检测按钮（内含算力问号） + 折叠一个检测项可有多条错误，逐条展示「序号 + 违规/疑似违规 + 原因 + 原文（文字类，命中词高亮）或原图（图片类，缩略图 + 来源说明）+ 建议方案」；图片类不展示识别内容文字，识别到的内容写进原因，原图来源只用首张主图 / 主图 / 详情图，不带序号，点击可看大图；有违规即按违规展示；超过 1 条时标题后显示「N 处违规 · N 处疑似」；通过 / 失败默认折叠，失败在头部直接带失败原因
检测记录入口下拉唯一二级项「查看检测记录」；每条检测项卡片内另有自己的「检测记录」下拉无任何记录时提示「暂无检测记录，完成一次检测后可查看」；有记录直接打开最近结果。记录按检测项分别保存，卡片内下拉可切换该项的历史轮次，切到历史显示「历史记录，仅查看」并隐藏重检与点赞点踩
算力每项单独计费，整单消耗 = 6 项消耗之和入口问号提示整单消耗，卡片「重新检测」后的问号提示单项消耗；原型统一用 xx 占位，真实数值以后端定价为准
演示场景标注面板「演示场景」两档：全部通过 / 违规 + 疑似 + 失败重算 6 项当前结果，切换即时生效、不新增记录、不扣算力
状态演示结论条「结论状态」、每张卡片「卡片状态」结论条可切全部通过 / 未通过，卡片可切通过 / 违规或疑似违规 / 检测失败；只改展示样式，不改检测数据、不写检测记录
  • 记录按检测项分别保存：整单检测等同于同时发起 6 项检测，每项各新增一条记录，不覆盖旧记录；每项最多保留最近 20 条，序号按该项累计。
  • 单项重检：当前轮归档为该项上一轮，卡片先显示「检测中」约 0.8 秒再写入新结果；卡片标题下出现「第 N 次 · 时间」下拉，可切换该项更早轮次。
  • 反馈挂在每条检测结果上，不按检测项聚合，且只做负面反馈：每条违规 / 疑似违规结果底部有「检测不准？」，点击弹原因多选（误报 / 漏报 / 原因不准 / 建议不准 / 其他）与补充说明，至少选一项或填写说明才能提交，提交后该条下方显示「已反馈：…」；通过态和检测失败不提供反馈。
  • 演示数据覆盖全部错误形态：知识产权为 3 条（标题命中 S25 Ultra、S26 两个品牌型号词 + 主图检出品牌 logo），违法违规为 1 条（详情图检出外部网址与扫码信息），材质为 1 条疑似（属性材质与首张主图识别结果不一致）；图片类错误均带缩略图，价格为检测失败，尺码与类目通过。 重检后知识产权、材质、违法违规转为通过，价格由检测失败转为违规。

8. 标注

  • AI生成视频入口（红）：锚定视频区块的「AI生成视频」按钮，说明入口位置、参考图来源、生成中禁用、生成中弹窗、生成失败与重新生成、停止生成；并补充接口为 LinkFox 图生视频 v3（扣费标准链接）、模型 MiniMax H3、分辨率固定 768P、请求参数为参考图 / 时长 / 比例。
  • 参考图范围与上限（红）：锚定 AI 生成视频弹窗的参考图区块，说明最多 9 张、选择顺序、选满置灰、未选禁用、重开重置和分辨率展示。
  • 时长与比例（红）：锚定时长与比例区块，说明 5 / 10 / 15 秒、算力值用 xx 表示、自适应比例口径。
  • 商品合规检测入口与演示场景（红）：锚定页脚主按钮，说明整单检测 6 项、点击到出结果的节奏、每次新增记录不覆盖、算力按项累加且统一 xx 占位；节点带「演示场景」下拉控件。
  • 检测记录下拉与空态（红）：锚定箭头按钮，说明向上弹菜单、唯一二级项、无记录提示、有记录直接打开最近一次、检测中箭头可用。
  • 结果弹窗头部与批次切换（红）：锚定弹窗头部，说明批次倒序、历史批次只读、算力汇总与关闭方式。
  • 检测结论条与算力汇总（红）：锚定结论条，说明由 6 项状态汇总、两种视觉与右侧计数。
  • 问题检测项卡片（红）：锚定知识产权卡片，说明展开规则、信息顺序、参考信息不得为空、配色与「全部通过」场景下的表现。
  • 通过检测项折叠态（红）：锚定尺码卡片，说明通过态只留一行、不展示参考信息 / 建议 / 赞踩、仍可重检。
  • 单项重检、历史轮次与反馈（红）：锚定卡片操作区，说明重检流程与算力、轮次条与只读规则、点赞点踩与原因多选、反馈按批次存储。
  • 提交并更新价格接口（红）：锚定价格区块的「提交并更新价格」按钮，说明点击调用敦煌开放平台接口更新价格，并附接口文档链接。
  • 采购价默认值（红）：锚定「采购价」列头，说明采购价即采集价、选填，未填写时套用价格公式按 0 元处理。
