规格值模板（批量添加规格值）主规格

设计基底：src/themes/camel-captain-erp/DESIGN.md。按两张参考图分别还原两个弹窗，均为独立弹窗页：不还原宿主页面，整页为白底 + rgba(0,0,0,0.52) 灰遮罩，弹窗在视口内水平居中、垂直居中；进入页面默认关闭，页面中央提供两个入口 tab 与「打开弹窗」按钮。两个弹窗共用一个原型，通过 hash 页面切换。

页面 1：批量编辑-批量添加规格值（带左侧导航）#page=with-nav

  • 弹窗「批量添加规格值」（860×484，圆角 8），右上角关闭按钮；标题下方有 1px 分隔线。
  • 左侧导航宽 120，顶部 40px/项：「规格值添加」「图片添加」。当前项为橙色文字 + 右侧 3px 橙色指示条；两项仅作分类展示，不可点击切换。
  • 「规格值添加」页签：
    • 文本框上方为「规格值模板」栏（高 32）：左侧标签 + 模板下拉选择（默认占位「选择已有模板快速替换」），下拉右侧紧邻「创建模板」（橙色实心）、「管理模板」（橙色描边）；选中模板后，「管理模板」右侧出现「保存模板」。
    • 多行文本框占满内容区（高 264），聚焦时橙色描边；占位文案逐行为「请输入规格值，每行一个 / 如： / XXS / XS / S」，使用占位色。
    • 文本框下方提示「CTRL+回车 可换行」。
    • CTRL+回车（macOS 为 ⌘+回车）在光标处插入换行，不提交。
  • 底部按钮「取消」「确认」居中于右侧内容列下方；取消为白底橙描边橙字，确认为橙色实心。

页面 2：编辑产品-批量添加规格值（无导航）#page=plain

  • 弹窗同名（560×483，圆角 8），无左侧导航、无标题分隔线、无换行提示。
  • 文本框上方同样有「规格值模板」栏，控件与页面 1 一致。
  • 仅一个多行文本框（高 264），占位文案「请输入规格值，每行一个」，默认未聚焦（灰色描边），聚焦后橙色描边。
  • 底部「取消」「确认」在弹窗内水平居中。

规格值模板

  • 预置 3 个公共模板：
    • 「尺码模板」：6 行合成尺码 
      EUR34=US3=UK2=22.0CM
EUR35=US4=UK2.5=22.5CM
EUR36=US4.5=UK3=23.0CM
EUR37=US5=UK3.5=23.5CM
EUR38=US5.5=UK4=24.0CM
EUR39=US6=UK4.5=24.5CM
    • 「颜色模板」：红色、蓝色、绿色、黑色、白色、黄色，每行一个。
    • 「常规尺寸模板」：S、M、L、XL、2XL、3XL、4XL，每行一个。
  • 选择模板：下拉只显示模板名称，点击后把模板内容整体替换到文本框，并把该模板标记为当前模板；文本框失去焦点，橙色聚焦态消失。
  • 保存模板：仅在已选中模板时出现在「规格值模板」栏「管理模板」右侧；把当前文本框内容覆盖写回该模板，顶部出现绿色「已保存到模板「模板名」」提示，2 秒后自动消失。
  • 创建模板：弹出「创建模板」二级弹窗（480 宽），含必填「模板名称」、自定义下拉「模板类型」（公共/专属），下方说明「① 公共：所有子账号可见 ② 专属：仅当前子账号可见」。名称为空时输入框变红并提示「请输入模板名称」；确定后以当前文本框内容创建并自动选中，提示「创建成功」。
  • 管理模板：弹出「管理模板」二级弹窗（680 宽），表格列为「模板名称 / 模板类型 / 操作」；每行「编辑」「删除」（橙色实心小按钮）。编辑打开同名表单，可改名称和类型，确定后提示「保存成功」；删除先弹出「提示」确认（「确定要删除模板X吗？」），确定后移除并提示「删除成功」，若删除的是当前模板则清空选中。
  • 二级弹窗均带灰色遮罩与右上角关闭按钮，页面内滚动不影响底层弹窗；模板库在两个 hash 页面之间共享，切换页面后仍保留当次编辑结果。

通用交互

  1. 确认：文本为空时在文本框下方显示红色「请输入规格值」，弹窗保持打开并聚焦文本框；有内容时按换行拆分为规格值（去首尾空白、忽略空行），关闭弹窗并给出结果摘要「已添加 N 个规格值：A、B、C」。
  2. 取消或右上角关闭：关闭弹窗，页面中央显示「打开弹窗 / 重新打开弹窗」按钮，并提供「批量编辑-批量添加规格值 / 编辑产品-批量添加规格值」两个入口 tab；重新打开后文本框内容与当前模板选中态重置，模板库保留。
  3. 页面切换通过 #page=with-nav / #page=plain；切换后保持关闭状态，点击按钮再打开对应弹窗。

视觉口径

  • 主色沿用主题品牌橙 #FF7D29；标题 #303133，正文/输入 #606266，占位符 #C0C4CC，辅助提示 #909399，控件边框 #DCDFE6，分隔线 #E5E6EB。
  • 标题 18px/26；导航与输入 14px，输入行高 22；提示 12px；按钮高 36、圆角 4，两按钮间距 10。
  • 模板栏控件高 32、字号 12；模板下拉宽 240，选项只显示名称；二级弹窗标题 16px，表单输入高 36，表格表头浅橙底。
