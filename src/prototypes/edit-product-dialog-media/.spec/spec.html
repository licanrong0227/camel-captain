编辑产品弹窗（视频/主图/站外推广图） · 截图还原主规格

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

当前方案

  • 原型意图：按源截图 1:1 精准还原「我的商品 - 骆驼队长BI」页面上「编辑产品」弹窗在滚动到 视频 / 主图 / 站外推广图 区域时的视觉状态，供评审与后续 React 原型实现使用。
  • 使用场景：ERP 运营人员在编辑产品弹窗中维护视频、主图与站外推广图。
  • 当前表达：1912×867 viewport 下的静态高保真还原；仅还原弹窗本体，弹窗外一律以灰色遮罩（#7f7f7f）表达，不还原背景页面内容；无交互。
  • 叠加层：「主图拼图」弹窗（components/CollageDialog.tsx + collage.css，z-index 20），以开源 easy-collage 页面为基底改造而来；外层带 44px 弹窗标题栏「主图拼图」+ 右上角关闭按钮，无底部操作按钮；默认隐藏，由 <CollageDialog open={collageOpen} onClose={...} /> 的 open 控制，后续由用户在其他按钮上接入调起。
  • 拼图弹窗当前结构（2026-10-13 批注后）：无开源站顶栏；左栏「选择模板」保持原样；中间 3×3 画布 + 底栏仅「导出」（浅灰）与「上传到主图」（绿色主按钮）；右栏收窄至 216px，改名「可选图片」，标题右侧「上传」按钮，下方两列已上传图片示例（复用 assets/main-*.png，带分辨率角标），原参数调整内容与「重置所有参数」底栏已删除。
  • 拼图交互（2026-10-13 第 6 轮批注后）：空画布格文案「点击添加图片或从可选图片拖放到此处」，点击空格触发文件选择、可一次上传多张，数量不超过当前空格子数，提交后按顺序依次填入空格子；可选图片为 1:1 方形、仅支持拖拽落入指定格（不再点击入格）；已填格显示图片，鼠标滚轮缩放（1–3 倍）、放大后可按住拖拽平移可视区域；可选图片与已填格均在悬停时右上角显示删除按钮，分别删除该示例图 / 清空该格图像。状态由 CollageDialog 内 slots、samples 与隐藏 <input type=file multiple> 管理。
  • 上传替换确认弹窗（CollageDialog 内 confirmOpen，z-index 50）：点击「上传到主图」弹出「提示」，内容为「主图上传数量已达上限，是否继续上传并替换掉最后一张主图」，底部「关闭」与「上传并替换」两按钮及右上角 × 均关闭本弹窗。
  • 上传图片弹窗（components/UploadImageDialog.tsx + upload-image.css，z-index 40）：复用 auto-edit-dialog 的「上传图片」样式，ERP 橙色主题；含 本地/URL/引用 侧栏、单个/批量上传单选、拖拽上传区、取消/确认底栏；由拼图弹窗「可选图片」标题右侧「上传」按钮打开，取消/确认/关闭均关闭本弹窗；仅样式，选项不可切换。
