更新发布弹窗 · 主规格

本文档是「更新发布弹窗」当前有效方案的事实依据。原型最初由截图 1:1 还原，2026-10-15 按用户批注完成结构化改版，同日按第二批批注完成「循环刊登开关联动 + 备选首图上传弹窗」修订；当前方案以本文件与 src/prototypes/update-publish-dialog/index.tsx 为准。

当前方案

  • 原型意图：ERP 商品「更新发布」确认弹窗，配置发布时间与循环刊登策略（标题 / 主图），并约定当日刊登量达上限后的处理方式。
  • 使用场景：批量更新商品后确认发布；开启循环刊登后可配置循环次数与自动刊登策略，标题/主图策略决定每轮重试时如何变换内容。
  • 当前表达：Element UI 风格表单弹窗（宽 720px，内容超高时体内滚动），灰遮罩独立承载，不还原背景页面；控件包括单选、开关、日期时间选择器、时/分/秒时间选择器、卡片式增量配置、多行备选标题、图片上传（弹窗式）。
  • 联动规则：「循环刊登」开关关闭时，其下方的循环次数限制以外的内容——自动刊登策略区块与当日上限处理策略——全部隐藏；打开开关后才逐级展示。

当前假设

  • 用户批注写「点击立即发布时显示日期时间选择器，提示文字为：选择定时发布时间」；因提示文字含「定时」，实现为 选中「定时发布」时显示日期时间选择器，待用户确认。
  • 「备选标题策略」选中「插入增量前、后缀」时展开自己独立的增量配置（第四批批注要求），默认后缀开启、前缀关闭。
  • 循环次数限制为纯数字输入，默认 1，未设上限。
  • 第二批批注仅要求去掉「失败自动刊登」选项并「在发布时间下面新增 Switch 开关」，未给出开关命名；结合「打开了循环刊登之后才显示」的表述，开关命名为 「循环刊登」，待用户确认。
  • 「备选首图策略默认选中」按第五批批注落定为：主图策略默认选中「随机打乱」，其下「备选首图策略」子区块的「随机打乱」也默认选中且可点击。
  • 上传弹窗内「本地 / URL / 引用」页签与「单个 / 批量上传」单选为样式展示（不可切换），参照 auto-edit-dialog 上传弹窗；点击上传区可真实选图并追加到备选首图列表。
  • 「引用」页签的可用范围（批注要求，已加标注说明）：单个商品的更新发布中启用，可正常引用平台已有图片；批量更新发布的弹窗打开时禁用。本原型只呈现单个商品场景，故页签保持可用外观，禁用态由标注说明承载。

原型范围

本次呈现

  • 发布时间（立即/定时 + Element 风格日期时间选择器，时间部分为时/分/秒任意时间点三列）。
  • 循环刊登 Switch 与循环次数限制（数值控件，仅正整数）；开关打开后才展示下方的自动刊登策略区块与当日上限处理策略。
  • 自动刊登策略（*必填）：标题策略（随机打乱 / 插入增量前后缀 / AI 重新生成 / 备选标题 + 备选标题策略）、主图策略（随机打乱 / 备选首图上传 + 备选首图策略）；单选项横向同行排列、详情块另起一行，标题策略与主图策略均默认选中「随机打乱」。

  • 当日刊登上限处理策略（直接终止 / 次日继续 + Element 任意时间点选择器）。
  • 提交校验：循环刊登开启时至少启用一项策略，否则红字提示并阻止关闭。
