运营后台 · 商品报表

原型 id：ops-report-center ｜ 页面：product-report（唯一页面、默认页） ｜ 设计基底：src/themes/element-ui/DESIGN.md ｜ 更新：2026-11-05

当前范围：只保留「商品报表」。原客户报表页面、客户演示数据、备注/附件与导出功能已删除；旧的 #page=customer-report 链接会回到商品报表。保留顶部后台导航与运营浮层作为入口上下文。

1. 背景与目标

  • 商品报表汇总所有有销量的商品，支持按租户、店铺、商品、商品来源、上架方式查询，是运营复盘商品表现的唯一页面。
  • 本期只展示「区间内有销量的商品」的销量、销售额与订单数，并支持排序与分页；不提供商品下钻、趋势图和导出。
  • 原型内数据为演示数据，筛选、排序、分页均为真实本地交互，不以「演示」提示替代操作。

2. 页面结构

区域内容本版处理
顶部导航首页、租户、系统管理、会员中心、物流、运营、菜单及用户、设置；右侧图标与头像完整保留外观；仅「运营」可打开浮层
运营浮层帮助中心；公告（公告、公告审核）；会员报表（订单报表、销售报表、商品报表）保留入口上下文；仅商品报表可跳转，其余项静态
商品报表面包屑 + 筛选 + 4 张汇总卡 + 商品表格 + 分页唯一实现页面

路由：#page=product-report，也是默认页；不带参数时直接进入商品报表。

4. 商品报表

4.1 入口与面包屑

  • 入口：顶部「运营」浮层 → 会员报表 → 商品报表；商品报表为蓝色激活项。
  • 面包屑：运营 / 会员报表 / 商品报表。
  • 浮层点击外部、按 Esc 或再次点击「运营」收起。

4.2 筛选条

控件内容规则
时间今天、近7天、近30天（默认）、自定义单选；选「自定义」展开起止日期，默认近30天区间；开始日期不得晚于结束日期
租户全部 / 多选租户（客户 ID + 联系人）可搜索；空选 = 全部；标签可单独移除
店铺全部 / 多选店铺按租户联动；切换租户时清掉不在范围内的店铺；空选 = 全部
商品输入框，占位「请输入商品ID或标题」匹配商品 ID、商品标题
商品来源全部 / 手动创建 / 用户采集 / BAL刊登多选；空选 = 全部
上架方式全部 / 手动发布 / 循环刊登多选；空选 = 全部
按钮查询（橙）、重置查询应用条件并回第 1 页；重置恢复默认（近30天、全部条件）并查询

1920 宽下筛选与按钮同一行；窄于 1600 时筛选区换行，按钮换行后靠右对齐。本版不提供导出。

4.3 汇总卡

有销量商品数总销量总销售额总订单数
当前结果去重商品数Σ 销量（件）Σ 销售额（¥，千分位，两位小数）Σ 订单数

四张卡与列表使用同一份「当前查询结果」，不受分页影响；默认演示数据为 18 个商品、1,506 件、¥81,431.00、782 单。

4.4 商品表格

列：商品（缩略图 + 标题 + 商品 ID）、租户、店铺、商品来源、上架方式、销量、销售额、订单数。商品列左对齐，来源/上架方式居中，三个数值列与表头右对齐。

  • 默认按销售额降序；销量、销售额、订单数均支持升/降序；切换查询条件后回到默认排序。
  • 无数据时显示 Element 空状态：「暂无数据」+「所选条件下暂无有销量的商品」。
  • 行高 56px；缩略图 40×40、圆角 2px；标题单行省略，商品 ID 为 12px 灰色。
  • 只读，无行操作、无勾选、无商品详情下钻。

4.5 分页

演示数据 18 条，10 条/页（可选 10/20/50）；显示总数、上一页、页码、下一页与「前往 __ 页」；改变每页条数回到第 1 页，翻页保持当前查询条件。

5. 数据与口径

指标口径
有销量商品所选时间范围内 Σ 销量 > 0 的商品；无销量商品不出现
销量区间内订单商品件的数量之和
销售额区间内 Σ(成交单价 × 件数)，按支付时间归属；展示两位小数与千分位
订单数区间内包含该商品的去重订单号数量，同一订单多件计 1

演示数据按天生成 30 天序列，商品标题与缩略图一一对应；切换今天/近7天/近30天/自定义后，列表、汇总卡与排序结果同步重算。其中 3 个商品近 7 天无销量，用于验证时间口径。

6. 交互与状态

  • 筛选改动后点「查询」生效；「重置」恢复默认并立即生效；分页、排序只作用于已生效条件。
  • 多选下拉以标签展示已选项，支持清空；时间用单选；日期非法时就地提示且不应用。
  • 空结果：表格显示空状态，分页 0 条，汇总卡全部为 0。
  • 桌面端优先，最小适配 1280 宽；表格在更窄视口内允许横向滚动，页面不出现整页横向滚动。
  • 其他导航、其他菜单项、头像与右侧图标保留 hover 反馈但无跳转。

7. 实施边界

  • 做：后台导航与运营浮层、商品报表的筛选/汇总卡/表格/排序/分页/空状态，以及演示数据。
  • 不做：客户报表、订单报表、销售报表、帮助中心/公告等其他页面；导出；商品详情下钻；趋势图；维度聚合表；退款指标；真实接口与权限。
  • 不修改全局主题和公共组件；样式与代码留在 src/prototypes/ops-report-center/。

8. 假设

1. 租户、店铺、商品来源、上架方式使用多选（空选 = 全部）；时间范围为单选。

2. 汇总卡统计当前查询结果全量（不只当前页）。

3. 会员报表分组中保留订单报表、销售报表作为静态入口，商品报表为当前唯一可跳转页。

4. 商品缩略图复用项目现有商品素材，标题按图片内容配置。

9. 验收清单

  • 打开原型直接进入商品报表，面包屑为「运营 / 会员报表 / 商品报表」；旧客户报表链接回到商品报表。
  • 运营浮层中只有商品报表可跳转，商品报表为激活项。
  • 时间/租户/店铺/商品/来源/上架方式筛选生效；空选等于全部；店铺随租户联动。
  • 三项指标可排序；分页、跳页、每页条数、空状态均正常。
  • TypeScript 构建通过，提供商品报表预览链接。
