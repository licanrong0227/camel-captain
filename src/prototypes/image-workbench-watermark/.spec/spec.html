图像工作台弹窗（水印 tab）+ 添加水印弹窗 - 主规格

当前方案

  • 原型意图：1:1 还原线上「图像工作台」弹窗（内嵌开源编辑器 快图设计 vue-fabric-editor）水印页，以及点击「添加水印」后弹出的配置弹窗
  • 使用场景：商品图片批量处理时打开的图像工作台，在水印管理中创建/管理水印
  • 还原口径：独立原型 + 灰色遮罩（#7f7f7f），背后页面不还原；样式按线上实测值，保持编辑器原生 iView 蓝色风格（借壳开源编辑器先例，同主图拼图弹窗）

原型范围

页面 1：图像工作台弹窗（水印 tab 定位态）

  • 外层 Element-UI 弹窗壳：95% 宽、margin-top 15vh、无标题、右上角关闭按钮
  • 顶部工具栏（45px）：图像工作台 | 文件▾ 插入 | 网格开关（开）撤销/重做（禁用）| 预览 水印 下载▾ 保存 中文▾
  • 左侧 65px 图标菜单：AI编辑 / 文字 / 图层 / 水印（选中，#2D8CF0）
  • 水印管理面板（315px）：标题 + 添加水印主按钮 + 5 条水印（abc / 1 / 水印1 / 11111 / 撒大声地），每条 80×80 预览图 + 修改/添加/删除
  • 属性面板（260px，静态展示）：快捷操作、居中、替换图片/裁剪图片、图片滤镜（简单/复杂 + 8 张滤镜样本图）、图像描边、位置信息、阴影/颜色/模糊、边框、数据
  • 中间画布（#f1f1f1）：白色画布 + 当前商品图 + 选中框（8 控制点）+ 缩放按钮组
  • 最右图片列表（100px）：「图片列表 1 / 6」+ 6 张缩略图，首个蓝色选中框（#1890FF）

页面 2：添加水印弹窗

  • iView Modal：1110px 宽、top 10px、遮罩覆盖整个编辑器（含顶栏）
  • 必填「水印名称」输入框（320px，0/50 计数）
  • 三栏：工具条（添加文字 / 添加图片 + PNG 提示）｜650×650 空白画布｜属性面板空态「请选择一个对象进行编辑」
  • 底部：取消 / 预览 / 确认

本次不呈现

  • 背后「编辑产品」页面；其余 tab（AI编辑/文字/图层）面板内容
  • 添加文字/添加图片后的画布编辑流程、水印保存等真实功能
