当前方案

  • 原型意图：把用户提供的产品截图 1:1 还原成可评审的 HTML 主规格，作为后续 React 原型的唯一事实来源。
  • 使用场景：跨境 ERP「认领中心 - 批量认领」和「我的商品 - 批量编辑」两个入口共用的编辑产品弹窗。

事实与输入

用户确认事实

  • 还原范围：只需要实现截图中的弹窗部分，背景页面不属于交付范围。
  • 页面归属：认领中心 - 骆驼队长BI 的「编辑产品」弹窗。
  • 详情模板功能（2026-09-28 新增）：富文本框右上方提供模板下拉、创建模板、管理模板三个控件；创建模板把当前详情正文存为模板，下拉选中模板后用模板内容整体替换富文本框内容。
  • 模板下拉演示口径：下拉展示全部已保存模板，公共 / 专属仅作为类型标签展示，不在原型中按子账号过滤（用户已确认）。
  • 模板初始数据：预置示例模板 + 演示中可继续新建（用户已确认）。

原型范围

本次呈现

  • 弹窗容器：1720×780，圆角 8，标题「编辑产品」+ 右上关闭图标。
  • 左侧商品列表：10 行（缩略图 40×40、标题、编辑状态、行内删除/完成图标），首行为选中态（#fffaf5 底 + #ffb366 描边）；底部翻页按钮 2 个。
  • 右侧页签：基本 / 详情 / 日志，当前为「详情」（#ff781f），左侧「收起」双箭头图标。
  • 富文本编辑器：1px #cccccc 边框、45px 工具栏、9 组工具（B / I / U / 字号 / 字色 / 无序 / 有序 / 对齐 / 图片 / 清除格式），正文区为可编辑区域，默认为一张 1000×570 详情主图。
  • 工具栏右侧模板控件组：模板下拉（占位文字「选择已有模板快速替换」）、「创建模板」（主色按钮）、「管理模板」（描边按钮）。
  • 模板弹窗族：创建 / 编辑模板表单弹窗（模板名称必填 + 模板类型公共/专属 + 可见性说明）、管理模板列表弹窗（编辑/删除操作）、删除二次确认「提示」弹窗。
  • 右下角上/下滚动悬浮按钮，底部「关闭」「保存」按钮。

本次不呈现

  • 背景页面的导航、菜单、表格等真实内容 —— 仅按遮罩下可见的明暗色块做最低限度还原，用于承载 50% 黑色遮罩。
  • 页签切换后的表单内容、分页与选择逻辑（还原阶段为静态视觉稿）；富文本工具按钮仍为视觉态切换，详情模板控件与弹窗已实现（见「交互与状态方案」）。
