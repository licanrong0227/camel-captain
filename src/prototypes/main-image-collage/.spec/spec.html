主图拼图 · 原型主规格

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

当前方案

  • 原型意图：把「编辑产品弹窗-主图拼图」里的主图拼图弹窗单独提取为一个独立原型页，方便单独查看、评审和迭代。
  • 使用场景：为商品主图做多图拼版，从可选图片或本地上传取图，填进模板格子后上传到主图。
  • 当前表达：进入页面即为打开态——灰遮罩 + 1280×780 弹窗居中；关闭弹窗后页面停在浅灰底 +「打开主图拼图」按钮，可再次打开。
  • 模板驱动画布：左侧点选模板时，画布按该模板的矩形分块重建，格子数量、大小比例同步变化；整体画布固定 1:1（605×605）。
  • 保留原有 7/8/9 张模板，按三张参考广告拼图新增 23 张、20 张、11 张三套模板；2/3/4/5 张模板已删除。
  • 底栏「无缝拼贴」开关默认关闭：关闭时所有模板按原有 10px 缝隙拼贴，打开后格子之间无缝。
  • 右栏可选图片分为主图、站外推广图、SKU图、详情图四类，每个板块有独立全选，另保留全局全选。

原型范围

本次呈现

  • 主图拼图弹窗：标题栏、选择模板左栏、画布区与底栏、可选图片右栏。
  • 模板库：7/8/9/11/20/23 张模板；模板缩略图按真实分块绘制。
  • 画布：605×605（1:1），格子位置与大小由当前模板的矩形分块决定；小格子只显示「+」，悬停提示添加方式。
  • 拼贴方式：「无缝拼贴」开关控制全部格子间距——关闭 10px、打开 0；不改变格子位置与已填内容。
  • 可选图片：主图（4 张）、站外推广图（3 张）、SKU图（64 张，来自附件 SKU图_805250.zip）、详情图（4 张）四类；全局全选与各类独立全选。
  • 画布格子：点击空格打开上传图片弹窗、从可选图片拖入、滚轮缩放（1–3 倍）、放大后拖拽平移、格子间拖拽换位、悬停删除。
  • 可选图片：勾选/全选、删除、拖拽入格、「导入已选图片」。
  • 底栏：清空、导出（样式）、上传到主图（数量达上限时弹「上传并替换」确认框）。
  • 上传图片弹窗：本地/URL/引用、单个/批量、拖拽上传区、取消/确认。

本次不呈现

  • 编辑产品弹窗本体（左侧商品列表、其他栏目、保存/发布底栏）不在本原型内。
  • 真实图片上传、导出文件、上传到主图的后续链路；均为样式演示。
  • 模板缩略图不加载参考图原图，只用色块示意分块。

设计基底与原型特有调整

  • 采用的 DESIGN.md：src/themes/camel-captain-erp/DESIGN.md
  • 继承方式：拼图弹窗沿用来源原型中按开源 easy-collage 复刻的绿色体系（主色 #33c276、Poppins），上传图片弹窗与提示框沿用 ERP 橙色（#ff781f）；本原型不额外套用 ERP 主题 token，以与来源保持一致。
  • 本原型特有调整：仅遮罩增加滚动与内边距，窗口小于弹窗尺寸时可滚动查看，不做缩放；「无缝拼贴」开关与分区分组沿用拼图绿色主色（#33c276）。
