批量美图弹窗 - 主规格

还原范围

按线上「我的商品 → 行内编辑 → 编辑产品 → 主图 → 批量美图」打开的弹窗还原整套界面与交互，覆盖转白底、翻译、加水印、去水印、裁剪缩放五种处理方式，以及处理中、已完成、未保存退出三类状态和三个二次弹窗。

界面结构

  • 标题栏：左侧「批量美图」标题，右上角关闭按钮，底部一条通栏分隔线
  • 左侧处理方式列（120px）：转白底（默认激活）/ 翻译 / 加水印 / 去水印 / 裁剪缩放；激活项橙色加粗并在右侧显示 3px 橙色指示条
  • 图片位置页签：主图（默认）/ 站外推广图 / SKU图 / 详情图，下划线式激活态；每个位置各自维护图片、勾选与处理结果
  • 处理方式面板：裁剪缩放显示大小/宽度/高度；加水印显示水印模板、类型、内容、滑块、预览、位置；其余三种不显示面板
  • 操作行：左侧「全选」勾选框 + 「已选 N/M 张」；右侧橙色「开始处理」按钮，仅转白底在按钮内带问号算力提示（翻译的消耗在选择弹窗中说明，按钮不带问号）
  • 图片网格：120×120 卡片，选中态橙色描边 + 左上角橙色勾选圆标，底部半透明尺寸角标，右下角绿色「已完成」，悬停显示放大按钮，图下标注「图N」
  • 页脚：「取消」（橙描边）与「确认」（橙色实心）居中；有已处理图片时按钮上方显示「有已处理未保存的图片」

交互行为

  • 点击图片切换该图是否参与处理；「全选」勾选/取消当前位置全部图片，部分勾选时显示半选横杠；已选计数实时更新
  • 切换图片位置页签或左侧处理方式时，各自状态（勾选、已完成、尺寸）保留；处理中两者均禁用并置灰
  • 「开始处理」按勾选图片逐张处理：处理中按钮变为红色「停止处理」并显示转菊花，图片覆盖「处理中...」遮罩，页脚按钮禁用；全部完成后提示「图片处理完成」，每张标注「已完成」
  • 「停止处理」后按钮显示「停止中」，当前批次中断并提示「已停止处理：成功 N 张，未完成 M 张」；再次点击提示「停止处理中，请等待当前任务处理完成」
  • 未勾选任何图片时点击「开始处理」提示「请选择要处理的图片」
  • 「加水印」未填水印文字提示「请输入水印文字」；图片水印未上传提示「请先上传水印图片」；文字水印时字号可调，图片水印时大小可调，透明度与预览实时联动
  • 「去水印」点击开始处理后先弹出「去水印」版本选择（Pro版本 / 普通版，各带算力问号），选择后才开始处理
  • 「翻译」点击开始处理后先弹出「翻译」方式选择：全量翻译（每翻译1张图片消耗 xx 算力）或识别后翻译（AI 先识别是否含中文字符等需要翻译的内容，无需翻译时每识别1张消耗 xx 算力，需要翻译时翻译另需消耗 xx 算力），确认「开始翻译」后才处理
  • 「裁剪缩放」预设 1000*1000 / 800*800 / 自定义；改预设同步宽高，改宽高不是两个预设值时自动切到自定义；处理后尺寸角标更新为新尺寸
  • 「确认」在有已处理图片时可用，点击保存并关闭弹窗，提示「图片处理成功」；无已处理图片时禁用
  • 关闭按钮或「取消」：有已处理未保存图片时弹出「提示」，可选「退出」或「保存并退出」；无已处理图片时直接关闭
  • 点击图片放大按钮打开大图预览，点击遮罩关闭；图片支持拖拽调整顺序
  • 关闭后在遮罩上提供「重新打开「批量美图」」入口，重开恢复初始状态

二次弹窗

  • 提示：宽 460，正文「当前有已处理未保存的图片，退出后，已处理的图片将不会保存，是否继续退出？」，底部「退出」/「保存并退出」居中；右上角关闭仅关闭提示
  • 去水印：宽 420，提示行「请选择去水印版本」+ 两个描边按钮，底部「取消」
  • 翻译：宽 520，提示行「请选择翻译方式」+ 两张单选卡片（全量翻译 / 识别后翻译，含算力消耗说明），底部「取消」「开始翻译」，默认选中全量翻译
  • 图片预览：全屏深色遮罩居中大图

验收

  • 与线上弹窗逐项比对：970 宽、584 高（默认态）、左侧 120 列、120 卡片、按钮与角标样式一致
  • npx tsc --noEmit 本原型无类型错误；无头浏览器走通勾选、切换、处理、停止、保存、退出提示与重开链路
