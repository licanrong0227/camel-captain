# 子账号管理 · 主规格

## 当前方案

- 原型意图：还原骆驼队长「系统 / 账号权限 / 子账号管理」页面，作为可直接运行的运营中台后台页面，覆盖子账号列表、待审与我的申请三个视图，以及新增、修改、删除、重置密码、批量修改、批量新增、链接邀请等操作。
- 使用场景：管理员查看当前组织下的子账号、联系方式、角色、状态与最后登录时间；点击行展开行内操作修改资料、重置密码或删除账号；勾选多个账号后批量修改；通过单个新增、Excel 批量导入或邀请链接把新成员加入组织；在「待审」中处理邀请提交的申请，在「我的申请」中查看自己发出的申请。

## 页面与内容

### 子账号页签

- 页签：子账号 / 待审 / 我的申请，分段控件样式，当前项橙色。
- 筛选：关键词（160px 输入框）、部门（160px，空选项）、角色（160px，仅 Admin）；搜索、重置；新增、链接邀请、批量新增（仅子账号页签）；任一行被勾选后追加「批量修改」。
- 表格列：勾选、子账号(160)、姓名(120)、部门(120)、角色(140)、手机号(120)、邮箱(160)、添加/邀请人(120)、创建时间(160)、IP(120)、最后登录时间(160)、状态(100，居中)、备注(160)。表格总宽 1695，小于容器时随容器拉伸，大于容器时横向滚动。
- 点击数据行（勾选列按钮除外）在该行下方展开 49px 行内操作条，左侧依次为「修改」「重置密码」两个橙色小按钮，同一时间仅展开一行。
- 状态使用浅绿标签「启用」；停用为浅红标签「停用」。
- 分页：共 N 条、10/20/50/100 条每页、上一页/页码/下一页、前往 X 页。
- 待审：去掉状态列，空表显示「暂无数据」，不显示分页。我的申请：保留状态列，空表显示「暂无数据」，不显示分页。

### 添加子账号弹窗（800px）

- 页签：账号信息 / 菜单权限 / 店铺权限，橙色下划线。
- 账号信息字段：头像（上传头像按钮）、子账号（必填，右侧固定后缀 `@licanrongceshi@zsq888`）、姓名*、手机号*、邮箱*、部门（空选项）、角色*（Admin）、账户状态*（启用/停用，默认启用）、密码*、备注（多行）。
- 菜单权限：未选角色时显示「请先选择角色以查看对应的菜单权限」；选择角色后展示可展开的权限树，父子联动，支持半选。
- 店铺权限：左右穿梭框。「未选择的店铺」含全选、搜索、5 个店铺；「已选择的店铺(N)」含全选、搜索和空状态「暂未选择店铺」；中间为「添加 →」「← 移除」，无勾选时按钮禁用。
- 底部：确定 / 取消。

### 修改子账号弹窗（800px，行内「修改」）

- 标题「修改子账号」，页签与添加一致：账号信息 / 菜单权限 / 店铺权限。
- 账号信息回填当前行：子账号前缀（如 `licanrongceshi`，后缀同添加）、姓名、手机号、邮箱、部门（显示 `0 (unknown)`，可清除）、角色（Admin，标签形式）、账户状态、备注；编辑态没有密码字段。
- 菜单权限：当前角色 Admin 的菜单树全部勾选且禁用，仍可展开层级；店铺权限：已选择的店铺(5) 全选，左侧「暂无数据」，可调整后保存。
- 底部确定 / 取消；确定后更新列表行并提示「修改成功」。

### 重置密码（行内「重置密码」）

- 420px 居中消息框，标题「提示」、内容「请输入新密码」、输入框、取消 / 确定。
- 未输入点确定提示「请输入新密码」；输入后确定关闭并提示「密码重置成功」，原型不改真实密码。

### 删除子账号弹窗（520px，行内「删除」）

- 行内操作条在「修改」「重置密码」后新增红色描边「删除」按钮。
- 弹窗内容：当前子账号（姓名 + 账号）、红色风险提示「删除后将无法恢复，该子账号及其菜单权限、店铺权限等关联数据会被一并删除」、保留资料提示「如暂时需要保留资料但不希望该子账号登录，可以先禁用子账号」并带「禁用子账号」快捷操作。
- 主账号密码必填，用于删除前身份验证；未填写点确认提示「请输入主账号密码」。
- 倒计时确认：打开后 5 秒内「确认删除（Ns）」按钮禁用，倒计时结束变为「确认删除」才可提交；关闭重开重新倒计时。
- 点击「禁用子账号」关闭删除弹窗，将该行状态置为「停用」并提示「子账号已停用，账号资料已保留」。
- 确认删除后从列表移除该行、清空对应勾选与展开状态，并提示「删除成功」。

### 批量修改弹窗（800px，勾选行后出现）

- 工具栏在「批量新增」后追加「批量修改」，仅在至少勾选一行时显示。
- 页签：账号信息 / 菜单权限。
- 账号信息字段：部门（空，可清除）、角色*（Admin，标签形式）、账户状态*（默认启用）、密码（占位「不修改请留空」）。
- 菜单权限与添加弹窗一致：未选角色时提示「请先选择角色以查看对应的菜单权限」，选择角色后展示可勾选权限树。
- 底部确定 / 取消；确定后把部门（有值时）、角色、账户状态应用到所有勾选行，清空勾选并提示「批量修改成功」。

### 批量新增弹窗（480px）

- 提示「请先下载模板，按格式填写后再上传（支持 .xlsx / .xls）」、模板下载链接、拖拽/点击上传区、格式提示；底部取消 / 提交。

### 链接邀请弹窗（560px）

- 提示「已生成邀请链接，打开后由用户自行填写账号信息，提交后需审核。」、只读邀请链接、复制链接按钮；底部知道了。

## 交互与状态

- 搜索按钮与回车触发筛选；重置清空关键词、部门、角色并回到第 1 页。
- 页签切换清空当前勾选；待审/我的申请仅保留搜索、重置。
- 表格首列支持全选当前页、单选；分页切换页大小回到第 1 页。
- 行点击：点击数据行切换展开状态，再点同一行收起，点另一行则切换为另一行展开；勾选按钮只选中不触发展开；筛选、分页或切换页签时收起所有行。
- 行内操作：「修改」打开回填的修改弹窗；「重置密码」打开新密码消息框；「删除」打开风险确认弹窗。
- 删除：5 秒倒计时内确认按钮禁用；主账号密码必填，未填提示「请输入主账号密码」；确认后移除当前行并提示「删除成功」；「禁用子账号」直接把状态改为停用并保留账号。
- 新增：必填校验（子账号、姓名、手机号、邮箱、角色、密码；手机号 11 位、邮箱格式），错误提示显示在对应字段下方并切回账号信息页签；提交成功后按当前时间新增一行到列表，清空筛选并提示「添加成功」。
- 修改：必填校验（子账号、姓名、手机号、邮箱、角色），保存后更新当前行并提示「修改成功」；菜单权限只读，店铺权限可调整。
- 批量修改：角色必填；部门为空时不修改部门；确定后应用到全部勾选行并提示「批量修改成功」，按钮随勾选清空而隐藏。
- 菜单权限：选择角色后默认全选；点击父节点切换整棵子树，点击子节点同步父节点全选/半选状态；展开箭头独立于勾选。
- 店铺权限：勾选后「添加」把店铺移到右侧并更新计数，右侧勾选后「移除」移回左侧；左右搜索独立过滤；全选只作用于当前搜索结果；无勾选时对应按钮禁用。
- 批量新增：模板链接下载真实 `子账号导入模板.xlsx`；仅接受 .xlsx/.xls，选择后展示文件名与大小，可移除；未上传提交时提示「请先上传文件」，提交后关闭并提示「批量导入任务已提交」。
- 链接邀请：打开时生成演示 token 链接；复制写入剪贴板并提示「复制成功」。
- 顶部「系统」悬停展开分组面板，当前项「子账号管理」橙色高亮；其他一级导航也可展开对应分组。

## 当前假设

- 线上行内操作只有「修改」「重置密码」；「删除」为 2026-11-26 用户新增需求，原型按需求补齐，不对应线上现有按钮。
- 删除弹窗的主账号密码只做前端必填校验，不校验真实密码；删除只移除本地演示行，不调用后端，也不实际删除关联数据。
- 删除后的「先禁用子账号」快捷操作直接把行状态改为停用，可再通过「修改」改回启用。
- 新增子账号的账号名按弹窗可见后缀生成：`输入前缀 + @licanrongceshi@zsq888`；修改已存在账号时按 `输入前缀 + @zsq888` 回写；添加/邀请人固定为 `zsq888`。
- 部门线上无数据，列表显示 `-`，修改弹窗回填 `0 (unknown)`；原型保留空下拉及 `No options available.` 空态，不编造部门数据。
- 修改弹窗中 Admin 的菜单权限线上为禁用只读，本轮同样只读；店铺权限回填 5 个店铺，可调整但列表不展示店铺字段。
- 重置密码只做消息框与成功提示，不写入或校验真实密码。
- 批量修改的菜单权限页签可操作，但列表不展示权限字段，本轮不做权限持久化展示；只有部门、角色、账户状态回写列表。
- 批量导入不解析 Excel 内容，提交只做前端上传校验和结果提示；真实导入由后台完成。
- 邀请链接中的 token 为演示随机串，不请求真实邀请接口。
- 顶部导航除「子账号管理」外的页面、任务管理器、消息、主题切换、个人中心等全局入口只还原外观，不实现跳转或真实业务。
