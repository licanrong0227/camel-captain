与线上的差异

  • 批量按钮组末尾新增「批量关联产品模板」入口（红色标注：此操作仅在“已上架”页面批量勾选商品时显示），样式与其他批量按钮一致；点击弹出同名弹窗，内容移植自 auto-edit-dialog-copy2 的按店铺产品模板区块。
  • 截图红框圈住的运费模板 / 售后模板 / 线上分组三个下拉与橙色「同步」按钮，按要求不移植；弹窗内每个店铺行只有产品模板、剩余展示位提示、新增/修改产品单选和说明文字。
  • 线上表格第一列的展开箭头列宽被压到 1px（不可见），本页未还原该列。
  • 商品标题、来源等外链指向线上真实地址，仅用于演示，不做跳转拦截。
  • 筛选区搜索条件下拉只保留「类目名称」一项；右侧改为 ElementUI 多选可搜索级联选择器（el-cascader + props.multiple + filterable）：点开按一级/二级/三级类目分列展开，勾选三级类目加入已选标签，勾选上级类目即选中其下全部类目、部分选中显示半选；在框内输入关键字实时搜索，结果按完整路径平铺并高亮命中文字，点击即勾选/取消；标签可单个移除、悬浮可一键清空，已选多个时折叠展示（只显示第一个标签 + 「+ N」，悬浮看全其余类目）、选择框高度固定不撑高，无匹配时显示「无匹配数据」。

关键样式约定

  • 主色 #ff781f；正文 #606266；辅助文字 #909399；表头底色 #f5f7fa；行分隔线 #ebeef5。
  • 勾选框 14×14、圆角 2；选中态橙色填充 + 白色对勾。
  • 「已上架」状态标签：文字 #4caf50、底色 #e8f5e9、圆角 12、内边距 2×10。
  • 售价 12px / 600 / 主色；产品编号 14px / 500；时间与版本 12px / 行高 18。
  • 批量按钮组 flex-wrap：窗口变窄时按钮换行堆叠，与线上表现一致。
  • 布局随容器伸缩：顶栏、筛选区、批量按钮组可换行；表格列在 800px 内按比例收缩，容器再窄时表格区自身横向滚动，内容不会溢出到卡片外。
  • 高度同样随容器伸缩：页面撑满视口不整页滚动，左侧统计列表与商品列表各自内部滚动，表头吸顶，批量操作按钮与分页控件固定在卡片底部。

批量关联产品模板弹窗

  • 遮罩 rgba(0,0,0,.28) 居中，弹窗宽 900px（窄视口下 calc(100vw - 24px) 收缩）、最高 calc(100vh - 48px)，标题栏 + 可滚动内容区 + 固定底栏；role="dialog" + aria-modal。
  • 内容区按店铺分行（服装测试 / bag / shoes），每行左侧店铺名、右侧模板配置，行间 1px 分隔线。
  • 产品模板下拉为演示数据：展示位剩余 2 / 5 / 0；下拉面板 position: fixed 定位、空间不足时向上翻、页面滚动即关闭，避免被弹窗裁切。
  • 选中模板后，下拉框右侧出现橙色「同步」按钮，点击弹出居中提示「同步成功」，2 秒后自动消失；「剩余展示位：N（最多 6 个展示位）」胶囊放在下拉框正下方，N 为 0 时转红色告警态，并把「新增产品」置灰、追加「（展示位已满）」。
  • 单选「新增产品 / 修改产品」选中后才出说明文字，两种模式的文案分别说明加入模板与替换模板的行为。
  • 取消 / 确定 / 关闭 / 点遮罩均只关闭弹窗，不做提交。
  • 第一个店铺行的模板区块挂了原型标注「关联产品模板：按店铺关联，数据来源与同步规则」，内容从 auto-edit-dialog-copy2 原样移植，说明模板数据来源、新增/修改调用的接口，以及剩余展示位与「新增产品」可选性的关系。
