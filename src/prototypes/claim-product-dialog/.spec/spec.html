认领商品弹窗

本文档是用户与 Agent 围绕当前原型进行方案沟通和持续生成的事实依据。当前版本按线上「认领中心 → 认领商品」弹窗做 1:1 还原。

当前方案

  • 原型意图：还原认领中心批量认领时弹出的「认领商品」弹窗，用于选择认领平台、目标店铺和认领方式（仅认领 / 认领并发布），认领并发布时可设置发布时间与循环刊登，并选择直接认领或自动编辑。
  • 使用场景：在认领中心勾选商品后点击「认领」，弹出本弹窗。
  • 当前表达：页面只保留弹窗本身，挂在灰遮罩上视口居中；左侧为待认领商品卡片，右侧为认领平台与店铺选择，下方为认领方式（含循环刊登配置），底部为状态、提示与两个操作按钮。
  • 认领方式：默认「仅认领」；选择「认领并发布」后出现「发布时间」（立即发布 / 定时发布）与「循环刊登」开关，打开循环刊登后内联展示从「更新发布弹窗」移植的循环刊登配置。

事实与输入

用户确认事实

  • 原型名称：认领商品弹窗。
  • 还原对象：线上认领中心当前打开的「认领商品」弹窗（已在浏览器中打开）。
  • 设计基底：camel-captain-erp。
  • 只呈现认领商品弹窗：认领中心列表等弹窗以外的背景内容不还原。
  • 新增「认领方式」：仅认领（认领到商品列表）与认领并发布（认领完成后同时发布）。选择认领并发布时显示循环刊登选项，打开后可配置循环刊登信息。
  • 选择认领并发布会显示发布时间与循环刊登选项；发布时间支持立即发布/定时发布，定时发布使用日期时间选择器。
  • 循环刊登配置项从 src/prototypes/update-publish-dialog 移植，包含循环次数限制、自动刊登策略（标题策略/主图策略及子策略）和刊登数量达到当日上限时的处理。

参考资料

  • 线上页面：https://test.kuachengjing.com/commodity/claim 的认领商品弹窗。
  • src/prototypes/claim-exception-dialog：同业务下的认领异常弹窗，沿用其「独立弹窗 + 灰遮罩」的承载方式。

当前假设

  • 弹窗宽度 700px，内容区最小高度 360px，店铺列表最多约 5 行，超出部分在列表内滚动。
  • 待认领商品为 1 个；平台仅「敦煌网」一个可选，默认选中。
  • 店铺列表示例沿用线上演示店铺：echvolt、运营测试-张诗淇专用、服装测试、shoes、bag。
  • 「直接认领」「自动编辑」的后续流程不在本原型展开，提交后仅给出轻提示。

原型范围

本次呈现

  • 商品卡片：商品图、标题（两行截断）、共 N 个商品。
  • 选择认领平台：平台卡片，选中态为橙色描边 + 右下角橙色勾选徽标。
  • 选择店铺：已选数量、全选、5 个店铺多选卡片，选中态为蓝色边框 + 浅蓝底 + 蓝色勾选框。
  • 底部：平台与已选店铺数、状态提示、直接认领、自动编辑。
  • 认领方式：仅认领（默认）/ 认领并发布；选择认领并发布时显示发布时间与循环刊登开关。
  • 发布时间：立即发布（默认）/ 定时发布；定时发布展示日期时间选择器（月历 + 时/分/秒），确定后回填日期时间。
  • 循环刊登配置：循环次数限制（默认 1）、自动刊登策略（标题策略、主图策略及子策略）、刊登数量达到当日上限时的处理。
  • 提交校验：定时发布未选时间、循环刊登开启但未启用策略、增量起始值为空时阻止提交并提示。
  • 灰遮罩背景，弹窗视口居中。

本次不呈现

  • 认领中心列表、筛选、分页等背景内容。
  • 直接认领与自动编辑的真实任务提交、进度和结果页。
  • 循环刊登配置的真实保存、下发和发布结果。
  • 多平台切换、店铺搜索/分组、跨页选择等线上扩展能力。
  • 真实接口数据、加载与失败重试。

设计基底与原型特有调整

  • 采用的 DESIGN.md：src/themes/camel-captain-erp/DESIGN.md
  • 继承方式：默认严格遵循（品牌色、功能色、中性色、字号行高、按钮规范、遮罩量级、阴影两档）。
  • 本原型特有调整：平台选中态使用品牌橙，店铺选中态沿用线上弹窗的蓝色多选表达；底部提示与按钮文案按线上现状保留。
  • 循环刊登配置沿用「更新发布弹窗」的控件与交互：开关/单选使用蓝色选中态，策略区浅底，子策略左侧蓝色强调条。

当前待确认事项

  • 「自动编辑」在真实流程中会打开自动编辑弹窗，本原型暂以轻提示代替，后续可按需接入。
  • 「认领并发布」及循环刊登配置的真实保存、任务下发与发布结果页未接入；循环次数限制的业务上限待确认。
  • 定时发布时间的真实接口校验、时区与可预约时间范围待联调确认。
  • 备选首图上传当前直接调起本地文件选择，未复用「更新发布弹窗」中的上传图片子弹窗（本地/URL/引用）。
  • 平台多于一个时的排列与切换规则（本轮线上仅敦煌网）。
