批量美图弹窗 - 主规格

当前方案

  • 原型意图：高保真还原「批量美图」弹窗的视觉样式和基础交互
  • 使用场景：电商后台批量处理商品图片时弹出的操作面板
  • 当前表达：单弹窗页面，包含选项卡、图片网格、选择控制和操作按钮

原型范围

本次呈现

  • 弹窗标题栏（标题 + 关闭按钮）
  • 四个选项卡：转白底、翻译、去水印、裁剪缩放
  • 橙色「开始处理」按钮
  • 全选复选框 + 已选计数
  • 6 张商品图片网格，含选中状态、尺寸标签和标题
  • 底部「取消」和「确定」按钮

本次不呈现

  • 选项卡内容的具体功能面板
  • 图片上传/拖拽功能
  • 后端 API 对接

对象/场景前置状态用户操作原型表现后续状态

全选复选框全选状态点击复选框取消所有图片选中所有图片取消选中

开始处理—点击按钮显示处理提示—
