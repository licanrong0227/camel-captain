骆驼队长 ERP · 全站原型

独立原型 src/prototypes/camel-captain-erp-console/ · 默认页 home · 39 个 hash 页面

线上真实 DOM/CSS 1:1 复刻 Element UI 原样式 本地快照

本原型不再按设计规范重新设计页面，而是直接使用线上 ERP（test.kuachengjing.com）在 1440×900 下渲染出的真实 DOM、Element UI 样式、主题变量与字体资源。页面布局、表格密度、页签、筛选区、个人中心会员卡、店铺看板等均以线上截图和 DOM 为唯一依据。

还原方式

  • 页面快照：data/live/<page>.json，保存每页 #app.outerHTML、bodyClass、标题。
  • 线上样式：legacy/css/ 下 7 个原站 CSS 文件，按线上加载顺序引入；图标字体在 legacy/fonts/。
  • 主题变量：把线上 <html> 上的 --menu-bg、--primary-color、表头渐变等变量还原到 :root，导航激活态、按钮、表头与线上一致。
  • 表单回显：快照丢失 Vue 运行时写入的 input value，已按选中项和页面数据补回（如下拉选中值、个人中心资料）。
  • 首页为登录后的真实工作台 /dashboard；销售趋势图与商品销售排行榜用线上截图区域补回（ECharts canvas 不会随 DOM 序列化）。
  • 分页：已抓取第 2/3 页快照的页面共 10 个（我的商品、认领中心、我的订单、采购单跟踪、国际物流、订单明细、店铺看板、子账号、操作日志、汇率），运行时点击页码/上一页/下一页会切换整页快照。

外壳与页面

  • 50px 顶栏 + 26px 面包屑条；品牌、9 项导航、右侧主题/菜单/帮助/消息/VIP/头像均来自线上 DOM。
  • 顶部导航、页面弧形页签、含 href 的链接会映射到对应 hash 页面。
  • 顶栏 hover 展开多级子菜单：500px 浮层、二级分组标题 + 三级页面网格，位置跟随导航项（top 50px、left 对齐标题），图标/激活项与线上一致；点击三级项跳转并关闭浮层。
  • 补齐线上 SVG sprite（131 个 symbol），导航、按钮、表格里的 svg 图标可正常显示。
  • 39 页全部通过 #page=<id> 深链打开，Make 左侧页面树按模块分组。

弹窗使用线上 DOM 与样式；点击遮罩/×/取消/关闭或 Esc 关闭；确定、保存、提交、发布类按钮只提示「演示环境不会提交」，不调用接口。快照内已渲染的隐藏弹窗（同步线上、导入产品等）也会按按钮文案直接打开；快照里只有关闭态空壳时，自动跳过并回落到抓取到的完整弹窗内容。

物流商与出入库入口

  • 物流商管理页没有「新增」按钮，实际入口是「物流商对接申请」；已接入线上申请弹窗（基础企业信息、联系方式、取消/提交申请）。
  • 出入库管理是条码作业台：选择 入库/出库、自动/手动入库后点击「开始作业」进入扫码页；入库隐藏入库方式，出库显示扫码出库。
  • 扫码入库/出库页支持返回 setup、扫码页 1/2/3 页分页；扫描按钮只提示「演示环境不会提交出入库」，不调用接口。

筛选与搜索

  • 筛选下拉可点开线上真实选项，选中后回填当前值；搜索会同时使用关键词和已选筛选项过滤当前快照行。
  • 重置清空条件并恢复全部行。
  • 日期范围使用线上 range picker 面板，点两个日期分别回填开始/结束。
  • 订单 7 个状态页签已接入各状态快照与第 2 页数据。

通用控件

  • 表格行勾选会同步 Element 勾选样式；表头全选；开关、单选、复选框可切换。
  • Element 页签切换会更新激活条并显示对应 pane；树节点可选中/展开。
  • 按钮型下拉菜单（导入/导出等）可展开并选择菜单项；每页条数下拉可打开。
  • 带排序箭头的表头可点击升降序；站内信支持分类筛选、标记已读、查看右侧详情。
  • 店铺看板支持单店/店群切换、门店切换、周期切换、成交/下单/流量/潜在页签切换。

其他

  • 顶部导航、商品页签、订单状态页签切换会路由到对应页面。
  • 页面内原有链接（如 1688 来源）保持外链。
  • 首页营销页的「立即使用」「帮助中心」等按钮为静态展示。

当前边界（如实说明）

  • 页面内容为线上快照：筛选查询、排序、日期选择、切换每页条数暂不重新请求数据；按钮保留线上外观。
  • 分页只覆盖已抓取第 2/3 页的 10 个页面，其余页面多为单页数据；未抓取页码点击会提示。
  • 行操作条按线上真实展开行接入 19 个页面；报表、操作日志等线上本身没有行操作的页面保持不生成。
  • 筛选/日期/搜索作用于当前快照行，不会重新请求全量数据；每页条数切换只更新显示并提示，不重新加载。
  • 首页周期单选、店铺看板日期范围只更新控件值，不重算后端指标；即时咨询线上账号暂无会话数据，保持空态。
  • 表格排序只重排当前快照已渲染行，跨页数据不参与。
  • 100 个弹窗已覆盖主要打开入口；物流商实际入口为对接申请（已接入），出入库是页面内两阶段作业流（已接入）。
  • 首页图表与商品销售排行榜以截图补回，图表本身不再交互；店铺看板下方的图表如未进入首屏，仍以静态快照呈现。

维护方式

  • 页面结构：直接更新 data/live/<page>.json；CSS/字体按线上原始文件替换 legacy/。
  • 新增交互：在 index.tsx 的 ROW_ACTIONS、BATCH_ACTIONS、DIALOG_ALIASES、VALUE_FIXES 中登记，不修改页面快照。
  • 旧的 React 页面与自建组件库已不再被入口引用，保留作交互参考；不要再以其视觉作为还原依据。
  • 重新抓取需登录态：temp/shop-sign/live-capture.cjs 与 .tmp/extract-live.cjs。
