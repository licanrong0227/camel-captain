个人中心 - 购买权益弹窗（骆驼队长BI）

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

当前方案

  • 原型意图：按截图高保真还原「个人中心 - 骆驼队长BI」的单独购买权益页面，并以弹窗形式呈现；默认先弹出「提示」引导购买。
  • 使用场景：打开原型即见「算力积分不足」提示弹窗；点「购买」打开购买权益弹窗（截图内容），点「关闭」或 X 关闭提示。
  • 当前表达：购买权益弹窗为全局共用弹窗，会根据用户进入弹窗的场景默认选中对应购买项目；弹窗开关为真实交互。

事实与输入

用户确认事实

  • 弹窗标题为「购买权益」，为全局共用弹窗：根据进入场景默认选中对应购买项目（算力积分不足→AI算力，创建店铺数量不足→店铺数量）。
  • 购买权益弹窗内「店铺数量」已可选用：进入购买权益弹窗后可在 AI算力 / 店铺数量 之间点击切换，选中项带对勾、面板跟随切换。
  • 购买权益弹窗默认隐藏；页面默认显示「提示」弹窗。
  • 提示弹窗：标题「提示」，按进入场景展示文案「算力积分不足，请先购买算力积分。」或「创建店铺数量不足，请先购买店铺数量。」，操作为「关闭」和「购买」（主操作，点击后打开购买权益弹窗并默认选中对应项目）。
  • 店铺数量选中面板按第二张截图还原：左侧卡片含「数量」步进器（值 1，静态）；右侧为「期限」档位 1月 / 3月 / 6月(9.5折) / 1年(9折，选中) / 2年(8.5折) / 3年(8折)，价格 ¥214.92；折扣为档位右上角橙色角标。
  • 主规格使用 HTML 格式。

原型范围

本次呈现

  • 「提示」弹窗（默认显示算力积分不足场景，可切换）：标题 + 关闭 X + 按进入场景变化的文案 +「关闭」「购买（主操作）」按钮。
  • 「购买权益」弹窗（默认隐藏，点「购买」后打开）：标题 + 关闭 X。
  • 购买权益弹窗内容：步骤条（① 选择当前态 / ② 支付 / ③ 完成）、CNY 币种 + 会员估算、购买项目卡片（默认按进入场景选中带对勾，可点击切换）、数量面板（AI算力：50点选中 / 1000点 / 3000点 / 10000点 / 50000点，¥1.75；店铺数量：左侧「数量」步进器 + 期限档位 1月~3年 带 9.5折/9折/8.5折/8折 角标、1年选中，¥214.92）、提交订单按钮。
  • 页面底部「演示入口」：用于切换两种进入场景（算力积分不足 / 店铺数量不足）。

本次不呈现

  • 支付、完成两个步骤的界面内容（截图未提供）。
  • 期限档位的选择交互和价格联动（保持静态展示，选中项固定为 1年）。
  • 截图中的打码 logo 与「联系客服」悬浮入口（已按用户删除，不再呈现）。
