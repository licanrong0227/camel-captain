原型发布地址 - 主规格

当前方案

  • 原型意图：单页工具页，集中查看已发布到 GitHub Pages 的原型清单和访问地址
  • 使用场景：产品/设计/开发需要分享或打开已发布原型时，从这里取链接
  • 当前表达：页面标题 + 一张四列表格（原型名称、需求概述、发布时间、发布地址）

原型范围

本次呈现

  • 14 个已发布到 GitHub Pages 的原型（未发布的原型不列出，如「Shopify 对接」）
  • 原型名称：取自 Make 侧边栏页面树中的展示名；前后台重名的「帮助中心」以后台/前台后缀区分
  • 需求概述：有序列表逐条概括该原型实现的功能（3-6 条，依据各原型主规格与代码核实）
  • 发布时间：该原型第一次成功发布到 GitHub Pages 的时间（北京时间，精确到分钟）
  • 发布地址：完整 URL，点击后在新标签页跳转到该原型发布页；每行地址旁提供「复制」按钮，一键复制该地址

本次不呈现

  • 未发布原型、主题、资源的发布状态
  • 发布时间、发布历史等附加列
  • 搜索、筛选、复制按钮等附加交互
  • 需求概述的完整需求文档（仅摘要，详情看各原型主规格）
