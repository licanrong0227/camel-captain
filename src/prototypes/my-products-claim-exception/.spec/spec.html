基于线上 https://test.kuachengjing.com/commodity/my-products（循环刊登视图）还原页面骨架， 新增「认领异常」筛选入口与异常提示，用于说明批量认领成功但部分处理失败的沉淀场景。

页面结构

区块本页表现
顶栏 / 面包屑 / 页签沿用线上：平台 Logo、主导航（商品高亮）、商品 / 商品管理 / 我的商品、商品采集 / 认领中心 / 我的商品（选中）
筛选区沿用线上搜索条件与按钮顺序；筛选、搜索、导入导出等仅静态展示，不还原交互
左侧统计发布管理新增「认领异常 2」新增，位于「待发布」上方并选中；其余分组与数值按线上当前数据显示（全部商品 9304、待发布 353、发布中 1、循环刊登 35、发布失败 85、已上架 2741、已下架 3080、审核未通过 2835、内容违规 173、品牌商投诉 1 等）
商品列表共 2 条认领异常商品；列为展开箭头 / 勾选 / 图片 / 商品信息 / 产品编号 / 售价 / 标签 / 时间版本 / 来源
认领异常提示条位于每条商品信息下方，红色底 + 红色描边 + 警示图标，直接展示全部异常文字，不提供查看、处理与发布入口
多项异常展示多条异常在同一提示条内逐条换行展示，每条以序号开头，不折叠、不弹窗

异常数据来自批量认领异常日志；商品本身已认领成功，进入「认领异常」列表等待人工处理，不会被自动发布。

交互与状态

  • 「认领异常」默认选中，选中态沿用侧栏橙色文字 + 浅橙底色。
  • 异常提示条直接展示文字，不提供查看详情、展开全部或弹窗。
  • 本页仅查看异常，不提供处理与继续发布操作；需要处理时进入编辑商品页完成。其余筛选项、分页、行勾选等按“仅还原界面”要求不实现业务逻辑。
  • 商品状态标签显示「认领异常」，样式为浅红底 + 红字；商品信息区不展示批量认领时间标签。

样式约定

  • 主色 #ff781f；正文 #606266；表头底色 #f5f7fa；行分隔线 #ebeef5。
  • 异常提示条：底色 #fef0f0、描边 #fbc4c4、文字与图标 #f56c6c、圆角 4、内边距 6×10、字号 12。
  • 多项异常逐行排列，序号与异常文字同色，不缩进、不折叠。
  • 页面主体沿用 1912 设计宽；行内提示条按内容自适应换行，不出现横向溢出。

说明

  • 本原型重点在界面表达，筛选、搜索、分页、勾选、导入导出等线上业务交互不还原。
  • 两条商品为演示数据，商品名称、编号、店铺与异常日志编号均按线上列表风格构造。
  • 本页只负责异常信息查看；处理动作在编辑商品页完成，不在本页提供入口。
