骆驼队长移动端 App 原型

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

当前方案

  • 原型意图：把 PC「智慧运营中台」的核心能力做成手机端 App 原型，给开发直接对照手机尺寸的样式与交互。
  • 使用场景：卖家/运营在手机上查看当日经营与广告数据、处理异常入口；查看个人资料、算力/积分资产与分销客户。
  • 当前表达：固定 375×812 画布，外套 393×830 手机边框，居中展示；不做自适应，所有尺寸写死，内部滚动。
  • 原型地址：http://localhost:53817/?projectId=make-project-2&p=camel-captain-app&page=login

当前假设

  • 登录接受任意非空账号 + ≥6 位密码；注册/重置验证码接受任意 6 位；不做真实 MFA/短信。
  • 「生成推广链接」在原型中按当前 origin + 邀请码生成，不代表线上真实链接。
  • 推广链接 Sheet 内点「复制链接」后，按钮原位变为绿色「✓ 已复制」，约 1.6 秒后恢复。
  • 分销数据来自线上有数据账号，用于原型展示，不进入首页/广告看板统计。
  • 忘记密码页纳入本期，因为线上登录页已有入口。

原型范围

本次呈现

  • 7 个页面：登录、注册、忘记密码、首页、店铺看板（底部 Tab：数据）、我的、分销中心。
  • 右侧页面目录：标注面板「页面目录」按 账号与注册 / 经营看板 / 个人中心 三组列出全部页面，每个页面下再分组列出弹层与二级界面（登录、注册页、忘记密码、协议/隐私、首页及各弹层、店铺看板及各弹层、我的及各弹层、分销中心及客户详情/注册时间），点击「页面」切到对应 hash 路由，点击「弹层」直接跳到该页并打开对应弹层。原型不做登录拦截，任意页面与弹层可直接访问，登录仅用于演示流程。
  • 首页：头部下方为推广轮播（左右滑动切换，可点圆点定位，不设左右箭头），其下为指标、异常提醒、经营趋势、店铺 TOP5、商品 TOP5、悬浮客服；公告入口在顶部图标。
  • 滚动与返回顶部：首页头部（品牌 + 同步）、数据页筛选条与「成交/下单/流量/潜在/广告」页签行（以及广告页签里的「店铺/商品/计划/成单词」视图页签，吸顶位置按上方页签行的实际底边动态对齐、吸顶时改直角，回顶部恢复卡片圆角）、我的会员卡在滚动时吸顶；首页和数据页滚动超过约一屏后右下角出现「返回顶部」按钮（首页位于客服按钮上方），点击回到顶部。
  • 长列表统一交互：完整榜单 / 商品 Top100 / 公告为全屏 Sheet，顶部页签与周期筛选固定、不随列表滚动；列表或懒加载加载完毕后底部显示「已经到底了」（广告明细、店铺对比同样适用）。
  • 完整榜单「等级」页签的店铺经营类目取一级类目并去重，可能为多个：默认显示「首类目 等N类」，点按类目文字从底部弹出「经营类目」弹层（店铺名 + 全部类目标签），关闭后回到榜单原位置；只有 1 个类目时直接显示名称、不可点，无数据显示「-」。
  • 商品 TOP5 / 商品排行点条目打开 SKU 明细 Sheet（可点行右侧带 › 箭头提示）：顶部为「主图 + 单行省略的商品名 + itemcode · 店铺名」，其下：顶部可切换「组合 / 颜色 / 尺码 / 图案」查看维度，非组合维度按规格值汇总（销量、销售额、订单数求和，按销量降序），每行展示缩略图、规格、销售额与「订单数 单 · 件数 件」，列表底部显示「已经到底了」。
  • 趋势卡横屏查看：首页经营趋势、店铺看板广告趋势、广告明细趋势均提供「横屏」入口，点击后整页切换为横屏；经营趋势横屏保留页签并铺开多曲线、图例可显隐，退出回原卡片。
  • 广告看板：店铺/时间筛选（店铺默认不勾选，未选即统计全部店铺，勾选后只统计所选；时间用底部滚轮选择年/月/日起止日期，另保留近1/7/30/60/90天预设；广告页签的筛选条显示当前 GMV 口径（剔除数据/原始数据），点开「数据口径」面板可切换口径并进入剔除设置，时间面板不含口径设置）；成交/下单/流量/潜在/广告五个页签；店铺页签含指标卡、单指标趋势、国家筛选与店铺对比（每行店铺是一张独立卡片，同广告板块卡片；标题右侧「指标 ↓/↑」排序按钮，弹窗可选排序字段与方向；卡片内店铺名后带所选指标的趋势缩略图（点缩略图弹出该店趋势弹窗：成交/下单/流量/潜在 4 个页签 + 当前页签的指标卡（名称 + 区间数值），点指标卡换曲线；横屏视图同样带 4 个页签与指标卡），指标收在一张小卡里，合计行与列表行同款小卡，含加载更多）；广告页签的 5 个广告指标卡与趋势同卡（点指标卡切换趋势，趋势不单设指标页签）、四视图、排序与明细，列表底部有「合计」（按当前筛选的行求和，比率类指标按汇总值重算，同其他页签样式；商品/计划/成单词视图各有广告类型筛选与搜索框（按视图独立记忆，只影响当前视图的列表与角标，不改变其他视图），店铺视图两者都没有、直接跟随顶部店铺筛选）；指标卡设置按页签生效。
  • 我的：资料卡、邀请码与推广链接、算力/积分、资料宫格、分销中心、修改密码、联系我们、退出登录（不含算力明细/头像编辑）。
  • 分销中心：数据看板（直接展示 8 条客户订单卡片，不再有顶部统计卡）、我的客户（6 个客户，默认只露出姓名搜索，右侧「更多筛选」展开用户名/手机号（两列）和注册时间（标题在上、两个日期控件与上方两列同宽对齐、中间不写「至」），收起后条件仍生效；下方客户卡片 + 15 字段明细；两个页签的列表底部都有「已经到底了」）；注册时间同样用底部滚轮选择起止日期。

本次不呈现

  • 不接真实接口、不做真实登录安全/MFA/短信、不做真实上传服务端。
  • 不做响应式/桌面布局/缩放；不提供 PC 全站导航、主题切换、暗色模式。
  • 不做会员中心、订单中心、发票管理。
  • 不做原型批注、Review、发布；本期不产出 annotation-source.json。
