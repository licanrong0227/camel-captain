广告看板 · 以商品链接为核心的整合数据底座

设计基底：src/themes/camel-captain-erp/DESIGN.md。系统位置：顶部导航「报表」→「广告」→「广告看板」；面包屑 报表 / 广告 / 广告看板。单页原型，页面 id ad-board。

1. 背景与目标

  • 需求评审结论：只看广告数据价值有限——平台广告后台已经能看花费与产出，卖家真正缺的是「广告投入 × 整店 / 单链接产出」的整合视角。
  • 本期目标：把广告数据与店铺经营数据、订单数据整合到一起，支撑三层判断——店群哪家最依赖广告、单店哪些链接在花钱、单个链接每次投放到底带回了多少产出。
  • 第一阶段只做数据底座，不做预警、调价建议、补单剔除、关键词追踪。

2. 页面结构

  1. 筛选条（吸顶）：店铺范围（全部店铺 / 单店）、时间（近 1/3/7/15/30 天 + 自定义，最长 31 天）、GMV 口径（剔除补单 / 原始数据）、剔除设置、重置、同步广告数据；下方一行显示两个数据截止日与当前剔除金额。
  2. 核心指标：广告消耗、广告 GMV、整店 GMV、广告 GMV 占比、ROAS，均带环比。
  3. 趋势：广告消耗 vs 整店 GMV 双线，共用金额轴，按天。
  4. 明细区：店群模式为「店铺横向对比表」，单店模式为「主链接表」，两者在同一个卡片内切换。
  5. 链接详情：右侧抽屉，含四个数、按天走势、多时间对比。

剔除补单整店 GMV 扣除「补单标签订单的金额 + 手动扣减金额」；链接产出 GMV 扣除被剔除的订单行剔除后占比与 ROAS 同步重算；广告消耗和广告 GMV 不变

4.1 补单剔除

补单会虚高整店 GMV、压低广告占比。默认口径为「剔除补单」，可在筛选条切换为「原始数据」对比。

  • 按订单标签剔除：店铺维度从系统标签里下拉多选（标签由用户自定义、数量可能很多，面板支持搜索与清空），订单命中任一已选标签即剔除；一个都不选表示不按标签剔除。
  • 手动补录：按订单号剔除指定订单，或直接填写一笔扣减金额（用于说不清是哪一单的情况）。
  • 影响范围：整店 GMV、广告 GMV 占比、ROAS、链接产出 GMV 按剔除后重算；广告消耗与广告 GMV 来自广告接口，不受影响。
  • 手动金额的归属：只落在整店 GMV，不拆分到具体链接。

5. 交互与状态

  • 筛选即改即生效；店铺范围切到具体店铺时自动进入单店模式，点「返回店群」或店铺表格行可来回切换。
  • 时间切到自定义时才出现起止日期；超出 31 天或不晚于广告截止日会就地提示，数据保持上一次有效结果。
  • 店铺表默认按广告 GMV 占比降序，数值列可排序；链接表默认按链接产出 GMV 降序，支持搜索、产出阈值、分页。
  • 没有广告投放的链接仍然展示，广告相关列显示「-」。
  • 点链接行打开右侧抽屉，Esc 或遮罩关闭；抽屉内多时间对比固定以广告截止日为终点。
  • 同步按钮只负责广告数据入库，同步中按钮禁用并显示滚动图标，完成后更新「最近同步」时间。
