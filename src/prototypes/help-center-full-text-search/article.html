产品概述

骆驼队长智慧运营中台是专门为敦煌网卖家打造的一站式运营管理系统。它将卖家日常运营的各个环节

选品上架、订单处理、采购配货、物流跟踪、数据复盘、客服咨询——集成到一个平台，帮助卖家实现多店铺集中管理、全流程线上化、运营效率大幅提升。

1.快速入门

1.1注册与登录

  1. 注册账号

  1. 访问骆驼队长官网，点击「注册」
  2. 输入手机号，获取验证码
  3. 设置登录密码（建议8位以上，包含字母和数字）
  4. 完成注册，使用手机号和密码登录
提示：如果您是企业员工，建议由管理员创建子账号分配给您，无需自行注册。子账号创建方法详见系统管理章节。

  1. 登录系统

  1. 访问骆驼队长登录页
  2. 输入手机号和密码
  3. 点击「登录」
  4. 首次登录建议修改密码并完善个人信息

  1. 常见登录问题

问题
解决方案

检查手机是否拦截短信；等待60秒后重新获取；如仍收不到，联系客服处理

1.2首次登录

新账号首次登录后，建议按以下顺序完成基础配置，即可开始使用系统：
  1. 店铺授权：进入「系统 → 店铺授权」，授权您的敦煌网店铺（详见系统管理章节）
  2. 同步商品：进入「商品 → 我的商品」，点击「同步」，同步线上商品（首次同步可能需要较长时间）
  3. 同步订单：进入「交易 → 我的订单」，点击「同步订单」，同步店铺订单
  4. 配置物流商：进入「物流 → 物流商管理」，启用并配置您使用的物流商（详见物流管理章节）
  5. 熟悉界面：浏览各功能模块，了解系统布局和操作入口
注意：首次同步商品量较大时可能需要30分钟以上，请耐心等待。后续系统会自动同步，不需要每次手动同步。

1.3 界面导航与基础操作

  1. 界面布局

  • 顶部导航栏：系统Logo、各功能模块入口（首页、商品、交易、采购、物流、报表、系统、工具箱、即时咨询）
  • 左侧菜单：当前模块的子功能菜单
  • 主内容区：当前功能的操作界面
  • 右上角：消息通知、帮助中心、个人头像（个人设置、退出登录）

  1. 基础操作规范

  • 页面刷新：如页面数据未更新，点击浏览器刷新按钮或按F5
  • 数据筛选：列表页支持多条件筛选，可按时间、状态、店铺等筛选
  • 批量操作：列表页支持勾选多条记录进行批量操作（如批量申报、批量标记）
  • 数据导出：报表页支持导出Excel，便于线下分析
  • 操作确认：重要操作（如删除、提交）会弹出确认框，请仔细确认后再操作

2.首页 Dashboard

首页是经营数据的集中展示页面，建议每天上班后首先查看。

  1. 核心订单数据（第一行）

展示当前账号下所有授权店铺的汇总数据：
  • 当日销售额（GMV）：当日成交金额
  • 当日订单量：当日订单数量
  • 商品销量：当日销售的商品件数（订单量≠销量，一个订单可能包含多件商品）
  • 退款金额：当日退款总金额
  • 退款订单数：当日退款订单数量

  1. 异常数据预警（第二行）

展示需要重点关注的异常数据，点击「查看详情」可跳转到对应订单列表：
  • 异常订单数量：订单取消、买家申请退款、等待协商结果、退款协议协商中、买家投诉到平台等异常状态的订单。可通过高级筛选进一步筛选（如筛掉订单取消，只看投诉订单）
  • 剩余三天内发货：根据商品备货期倒计时，离备货截止还剩3天内的订单。采购和配货需要重点关注，数据一天更新一次
  • 超过7天未上网：订单生成7天后仍未产生第一条有效物流轨迹的订单。可联系物流商核实，阈值可在高级筛选中自定义修改
  • 超过20天未妥投：超过20天仍未妥投的订单，可能包含多种状态，可通过筛选进一步甄别
自定义说明：目前异常指标是标准化的，未来会支持自定义（如将"剩余三天发货"改为"剩余一天发货"）。当前可通过高级筛选临时调整筛选条件。

  1. 销售趋势与排行

  • 销售趋势：展示所有授权店铺的GMV走势（目前未剔除补单，未来会支持自动识别补单）
  • 店铺销售排行：各店铺销售额排名
  • 商品销售排行：热销商品排名

  1. 帮助中心

首页提供帮助中心入口，包括：
  • 整体操作流程图
  • 各功能模块详细操作指南
  • 演示视频

3.商品管理

3.1商品采集

把其他平台的商品信息一键抓取到本地商品库，无需手动录入。

支持采集的平台

当前版本已支持：亚马逊、1688、Temu、速卖通、敦煌网、SHEIN 共 6 个平台。

三种采集方式（页面上方三个标签页）

  • 链接采集：在大输入框粘贴商品链接（每行一个，支持批量），点「开始采集」。已导入的任务链接数会实时显示，可「清空链接」
  • 收藏夹采集：从 1688 / 拼多多收藏夹批量搬运商品
  • 采集记录：查看历史采集任务的成功/失败记录

采集步骤

插件下载并启用：

  1. 在「商品采集」页面找到插件下载提示，点击下载插件压缩包
  2. 解压压缩包（注意：解压后的文件要再下一层，文件名不带数字的才是插件文件夹）
  3. 打开Chrome浏览器，地址栏输入 chrome://extensions/ 进入扩展程序页面
  4. 开启右上角「开发者模式」
  5. 点击「加载已解压的扩展程序」，选择解压后的插件文件夹
  6. 确认插件已启用，浏览器右上角显示插件图标
采集过程：
  1. 进入「商品 → 商品采集」页面
  2. 打开选品网站，找到要采集的商品
  3. 复制商品详情页链接
  4. 回到骆驼队长，将链接粘贴到采集输入框
  5. 点击「采集」按钮
  6. 等待采集完成，采集成功的商品会出现在「认领中心」
采集失败排查：如采集一直显示"采集中"最后失败，请检查：①插件是否已启用；②插件是否为最新版本；③复制的是否为商品详情页完整链接；④网络连接是否正常。如仍失败，联系客服处理。

3.2 认领中心与自动编辑

3.2.1 批量认领流程

  1. 进入「商品 → 认领中心」，查看已采集待认领的商品
  2. 勾选需要认领的商品（建议同类型商品一起认领，共性条件越多，需要编辑的项越少）
  3. 点击「批量认领」按钮
  4. 选择认领方式：
    1. 直接认领：不做任何编辑，直接到「我的商品」，后续手动逐条编辑（不推荐）
    2. 自动编辑：使用AI和预设模板自动编辑商品信息（推荐）
  5. 选择要刊登的店铺（可选择一个或多个店铺，店群模式下可批量刊登到多个店铺）
  6. 设置自动编辑项（详见下文）
  7. 点击「提交认领」，系统在后台自动完成认领和编辑

3.2.3 保存为模板

所有编辑项设置完成后，点击「保存为模板」，输入模板名称。下次认领同类型商品时，直接选择该模板，所有设置自动套用，无需重复配置。
建议按品类分别设置模板（如服装模板、3C配件模板、家居用品模板等）。
效率提升技巧：使用AI自动编辑+模板功能，商品刊登效率可提升80%以上。传统方式每件商品编辑需要10-15分钟，使用AI自动编辑后仅需1-2分钟。

3.3 我的商品与刊登

  1. 商品列表与筛选

  • 进入「商品 → 我的商品」，查看所有已认领的商品
  • 支持按店铺、类目、状态、上架时间等筛选
  • 支持搜索商品标题、SKU等关键词

  1. 商品编辑

  1. 在商品列表中找到需要编辑的商品
  2. 点击「编辑」按钮，进入商品编辑页面
  3. 修改需要调整的信息（标题、价格、库存、详情页等）
  4. 点击「保存」

  1. 商品刊登

  1. 在商品列表中勾选需要刊登的商品
  2. 点击「刊登」按钮
  3. 确认刊登店铺和商品信息
  4. 点击「确认刊登」，系统自动提交到敦煌网
  5. 刊登成功后，商品状态变为「已刊登」
刊登报错常见原因：①类目属性缺失（补全必填属性）；②详情页图片超过8张（删除多余图片）；③价格超出平台限制（调整价格）；④标题包含违规词（修改标题）。如遇其他报错，查看报错提示或联系客服。

  • 操作记录（订单状态变更历史）

4.2 订单处理流程

订单处理的标准流程如下：
  1. 订单同步：同步敦煌网订单到系统
  2. 订单审核：检查订单信息，确认无异常（如地址错误、库存不足等）
  3. 批量申报：填写申报品名、申报价格、申报数量（用于国际物流报关）
  4. 线路审核：选择物流渠道，审核通过后进入采购配货环节
  5. 采购配货：1688采购或线下采购（详见采购管理章节）
  6. 申请运单号：采购完成后，向物流商申请运单号
  7. 打印面单：打印物流面单，贴单发货
  8. 提交平台：在系统中提交平台发货，敦煌网订单状态更新为已发货

4.3 批量处理申报信息

  1. 在订单列表中勾选需要处理的订单
  2. 点击「批量申报」按钮
  3. 统一设置申报品名、申报价格、申报数量
  4. 点击「确认」，批量完成申报
申报信息建议：申报品名使用英文，准确描述商品；申报价格建议为商品实际售价的30%-50%，不要过低或过高；不同国家有不同的海关要求，发货前了解清楚。详见常用工具包中的「申报信息参考模板」。

4.4 线路审核与物流渠道选择

  1. 申报完成后，订单进入「待线路审核」状态
  2. 勾选订单，点击「线路审核」
  3. 选择物流渠道（可按目的国、商品价值、时效要求选择最优渠道）
  4. 点击「审核通过」，订单进入采购配货环节

4.5 订单标记与自动打标

  1. 手动标记

  1. 在订单列表中勾选需要标记的订单
  2. 点击「标记」按钮
  3. 选择或输入标记内容（如"高价值订单"、"需关注"、"巴西订单"等）
  4. 点击「确认」

  1. 自动打标配置

  1. 进入「交易 → 自动打标配置」
  2. 点击「新增规则」
  3. 设置触发条件（如订单金额≥100美元、目的国为巴西、包含特定SKU等）
  4. 设置标记内容
  5. 保存规则，系统自动对符合条件的订单打标
订单标记后，可在订单列表中按标记筛选，优先处理重要订单。

5.采购管理

5.1线上采购

  1. 采购账号授权

  1. 入「系统 → 采购账号授权」
  2. 点击「新增」，选择平台「1688」
  3. 跳转到1688授权页面，输入1688账号密码完成授权

  1. 1688采购下单

  1. 订单线路审核通过后，进入采购配货环节
  2. 在订单列表中勾选需要采购的订单
  3. 点击「1688采购」
  4. 系统自动匹配1688商品链接（如未匹配，手动输入）
  5. 编辑采购信息（数量、规格、收货地址等）
  6. 点击「提交采购」，系统自动在1688下单
  7. 在「采购 → 采购单跟踪」查看采购状态

5.2 线下采购与供应商管理

 

创建供应商

  1. 进入「采购 → 供应商管理」
  2. 点击「新增供应商」
  3. 填写供应商信息（名称、联系人、联系方式、地址等）
  4. 点击「保存」

  1. 线下采购下单

  1. 订单线路审核通过后，进入采购配货环节
  2. 勾选订单，点击「线下采购」
  3. 选择已创建的供应商
  4. 确认采购信息，点击「确定采购」
  5. 采购单状态变为「待供应商确认」

  1. 供应商专属系统

供应商可以通过专属系统核对采购信息：
  • 确认：核对信息无误后确认，采购单状态变为「已采购」
  • 确认并发货：核对信息后直接发货，选择物流商并填写运单号，采购单状态变为「已采购」
供应商确认后，回到采购单页面即可追踪物流轨迹。
效率提升：线下采购通过供应商专属系统，实现采购信息在线核对和确认，避免电话/微信沟通的混乱，采购状态实时可追踪。

5.3 采购单跟踪

  • 进入「采购 → 采购单跟踪」，查看所有采购单
  • 采购单状态流转：待供应商确认 → 已采购 → 仓库处理中 → 运输中 → 已完成
  • 支持按状态、供应商、时间筛选
  • 点击采购单号可查看详情，包括采购商品、物流信息、操作记录等
  • 复制已采购单号，到采购单跟踪页面输入订单号即可查询商品信息，也可以做编辑和物流轨迹查询

5.4 代发打包与出入库管理

出入库管理支持两种模式，适用于不同的运营场景：

  1. 批量模式（适合SKU规范、自有仓库）

适用于批量入库、批量出库，本地SKU设置规范的商家。
  1. 进入「采购 → 出入库管理」，选择「批量模式」
  2. 扫码入库：用扫描枪扫描快递面单，系统自动入库
  3. 批量出库：勾选订单，批量出库
  4. 提交平台：出库后批量提交平台发货

  1. 手动模式（适合代打包、一单一发）

适用于在第三方仓库代打包、仓库和运营不在一起、一单一拆一打包一发货的商家。
  1. 进入「采购 → 出入库管理」，选择「手动模式」
  2. 点击「开始作业」
  3. 用扫描枪扫描快递面单（普通通用扫描枪即可，无需特殊配置）
  4. 系统自动带出对应订单信息，左侧显示采购包裹信息，右侧显示原订单信息
  5. 核对商品信息，确认无误后选择操作：
    1. 确认入库：先入库，后续再出库（不推荐，一般有问题时使用）
    2. 列入异常：商品有问题（颜色不符、款式不符、到货问题等），上传异常图片，登记异常
    3. 入库并出库：核对无误，直接出库
    4. 入库并出库并提交平台：打包完成，直接发货，系统弹出物流面单，打印贴单即可

手动模式优势：扫码自动匹配订单，无需在海量订单中查找；异常订单及时标记，便于后续处理；一键完成入库、出库、提交平台，大幅提升仓库作业效率。

常见问题

商品相关

Q：敦煌网采集一直显示"采集中"最后失败？
 A：检查①插件是否已启用；②插件是否为最新版本（卸载旧版重装）；③复制的是否为商品详情页完整链接；④网络连接是否正常。如仍失败，联系客服。
Q：插件安装后不生效？
 A：确认在扩展程序页面插件开关已打开；确认加载的是正确的插件文件夹（解压后再下一层，文件名不带数字的）；重启浏览器后重试。
Q：刊登报错"类目属性缺失"？
A：进入商品编辑页面，补全类目必填属性（带*号的字段），保存后重新刊登。
Q：刊登报错"详情页图片超过限制"？
A：敦煌网详情页最多8张图，删除多余图片后重新刊登。
Q：如何快速刊登大量商品？
 A：使用AI自动编辑+模板功能：认领时选择AI生成标题/关键词/五点描述，设置价格公式，保存为模板，下次一键套用。同类型商品批量认领，效率提升80%以上。

订单相关

Q：订单同步失败？
 A：检查店铺授权是否有效（重新授权）；检查网络连接；如持续失败，联系客服。
Q：运单号申请失败？
 A：检查①物流商API配置是否正确（测试连接）；②物流商账户余额是否充足；③订单重量是否超出渠道限制；④目的国是否支持该渠道。如仍失败，联系物流商或客服。
Q：如何批量处理订单？
 A：在订单列表中勾选多条订单，使用批量申报、批量线路审核、批量申请运单号等功能。

采购相关

Q：1688采购下单失败？
A：检查①1688采购账号是否已授权；②1688账号是否正常；③商品链接是否正确；④收货地址是否完整。如仍失败，联系客服。
Q：物流轨迹一直不更新？
 A：物流数据同步有滞后（约一天更新一次）；如超过7天未更新，在物流轨迹页面筛选"断更"订单，联系物流商核实。
Q：包裹显示"到达待取"怎么办？
 A：部分国家（如南非）不送货上门，需要买家自提。及时通知买家前往自提点取货，自提点地址可在物流轨迹中查看。
Q：如何降低物流成本？
 A：①配置多家物流商，对比选择最优渠道；②按目的国匹配专线物流（比商业快递便宜50%以上）；③按商品价值匹配渠道（低价值用邮政小包，高价值用专线/快递）；④及时处理物流异常，减少丢件损失。

系统相关

Q：如何给新员工开通账号？
 A：管理员进入「系统 → 子账号管理」，点击「新增子账号」，填写信息、选择部门、绑定角色，保存即可。新员工通过手机号登录。
Q：角色和子账号有什么区别？
A：角色是权限的集合（如"运营"角色拥有商品、订单、采购等权限）；子账号是具体的用户账号。一个角色可以绑定多个子账号，一个子账号也可以兼任多个角色。
Q：店铺授权后看不到商品和订单？
A：授权完成后需要手动同步商品和订单。商品同步：商品→我的商品→同步线上；订单同步：订单→我的订单→同步店铺订单。首次同步可能需要较长时间。
Q：系统卡顿或页面加载失败？
 A：①检查网络连接；②清除浏览器缓存；③使用推荐浏览器（Chrome或Edge）；④避开高峰期操作；⑤如持续卡顿，联系客服。

5. 实用小技巧

  • 批量搜索：双击搜索框可一次输入多个订单号（每行一个）
  • 快速筛选：点顶部状态标签一键筛选对应状态的订单/商品/采购单
  • 列表自定义：点「设置」/「列表设置」自选显示列
  • 导出数据：几乎所有列表页都有导出按钮，可导出 Excel 二次分析
  • 异常预警：首页 4 个预警卡片右上角「设置」可自定义提醒规则与阈值
