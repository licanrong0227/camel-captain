分区内容与控件默认状态 / 示例
通用规则只有一条通用规则，适用于全部商品；不提供规则列表、规则命名、优先级或适用范围选择。表单只包含模板段块与生成预览。一条规则，默认工厂 ABC

流水号方式一「自增」：可配置起始值与位数（位数 4-8），默认起始 1、5 位；由系统生成，允许重复。方式二「字段截取」：来源商品编码 / 类目编码 / SKUID，取前 N 位或后 N 位，N 1-12，并可保持原样 / 转大写 / 转小写；方式三「随机数」：只配置随机位数 4-12。订单级生成，自增流水按每个商品共享一个序列；自增始终基于当前最大序号递增，修改模板/规则后序号不清零，仍在原数值上继续自增。自增：起始 1、5 位 → 00001；字段截取：类目编码前 3 位转小写 → c10；随机数：4 位示例 4827
自定义变量 / 常量。变量：来源商品编码 / SKUID / 原始类目编码 / 随机数；字段类可选前/后 N 位与保持/大写/小写，随机数只配置 4-12 位；常量：手填字母数字，1-12 位，按输入原样保留。可添加多个自定义段。常量 V1；常量 BLK；随机 4 位示例 4827
类目缩写码配置第二层嵌套弹窗：树形类目，可在任意一级填写缩写码（不自动大写）；顶部配置「通用缩写码」，并提供「当前类目没有缩写码时」单选：使用通用缩写码 / 继承上一级缩写码（默认继承）。通用缩写码必填，为空时显示红色错误并禁用「保存」。表格列为类目名称、缩写码、生效值（含「当前类目 / 继承 X / 通用」来源），支持搜索与展开收起。默认继承：服装 CL、T恤 TS、短袖T恤继承 TS、长袖T恤 LT、电子 EL、耳机继承 EL、家居与收纳使用通用 GEN
生成预览固定使用演示商品「电子-蓝牙耳机」计算，不提供示例商品下拉。类目片段只做演示，不识别示例商品类目，始终显示通用缩写码并标注「通用」；通用缩写码未配置时直接报错。其他段按示例商品计算。ABC-GEN-2600001-V1（18 位，格式合法）

状态口径

  • 弹窗每次重新打开都回到「订单列表」页签与默认值（原型行为，不代表线上持久化）；nsPid 开关、配置与「已配置」标记一并重置。
  • 提示为顶部居中浅绿成功条，2.5s 自动消失，不遮挡弹窗标题；配置弹窗内的校验提示同样使用该提示条。
  • IM 输入框为空时仍可点击「翻译」，按空文本处理并提示成功。
  • NS-PID 配置弹窗为第二层模态（880×720，遮罩 rgba(0,0,0,.5)），不点击遮罩关闭，只能通过取消/关闭放弃修改；类目缩写码弹窗为第三层（720×620）。
  • nsPid 开关开启但未保存生成规则时，父弹窗「确定」被拦截，需先进入设置保存规则或关闭开关。
  • NS-PID 配置在配置弹窗点击「保存」时立即回写并显示「已配置」；父弹窗的取消/确定只关闭父弹窗，不撤销已保存的 NS-PID 配置。
  • 生成规则为订单级：每次生成按规则拼接，自增流水由系统生成并允许重复；同一商品共享一个序列，不同商品各自从起始值开始。预览只展示起始值/当前示例值，不做真实递增。
