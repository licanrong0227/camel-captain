基础配置三页面（渠道定价 / 上新价模板 / 店铺模板）主规格

设计基底：src/themes/camel-captain-erp/DESIGN.md。还原线上 商品 / 基础配置 下三个页面，共用顶部导航壳（商品下拉含基础配置三项，激活项橙色胶囊）；另含一个独立还原的弹窗页（页面 4），不带导航壳。

页面 1：渠道定价配置 #page=pricing

  • 筛选：模版名称输入 + 搜索（主按钮）/重置；右侧 新增/导入/下载模板。
  • 表格：模版名称、渠道单价RMB/KG、挂号费RMB/票、操作人、操作时间（无操作列）；9 条线上数据；分页条静态。
  • 新增弹窗（1000px）「新增定价模版」：编辑模版名称（必填，360px 输入）；配置定价规则 + 绿色提示「如果产品重量不足0.05KG，将会按照最低重量0.05KG计算价格」；规则行 = 重量 最小 ≤ ——＜ 最大 KG、单价 RMB/KG、挂号费 RMB/票；首行右侧「新增配置」追加规则行，其余行「删除配置」；确定校验必填后新模版入表（多档价格显示为 低~高），取消关闭。
  • 导入/下载模板点击提示「演示原型，未接入实际功能」。

页面 2：上新价模板配置 #page=new-arrival-price

  • 筛选：店铺名称下拉（请选择店铺）+ 定价模版输入；搜索/重置/新增。
  • 表格：上新价模版名称、模板类型（公共/专属，每个账号只能查看和编辑公共和自己创建的专属价格模板）、操作人、操作时间（无操作列）；5 条线上数据。
  • 新增弹窗（1100px）「新增上新价配置」分区：
    1. 基础信息配置：模版名称*、模版类型*（公共/专属，默认专属；下方说明「公共：所有子帐号均可使用此模板」「专属：仅当前子帐号可见此模板」；平台与店铺已按批注隐藏）。
    2. 成本配置：采购成本/国内物流成本RMB/国际物流成本RMB 勾选（默认全选）；表格列 成本类型|变量/常量|公式|汇率转换成USD（实时汇率/固定汇率+数值）；采购成本公式可选 采集价（变量）、固定价（常量，单价+币种USD/RMB）、采集价折扣（变量，折扣为小数），其汇率列注明「仅在采集价为RMB时生效」，固定价且币种为 USD 时整列显示「-」、固定价且币种为 RMB 时不显示该提示；国内物流=常量4.00；国际物流=公式列最上方单选 渠道定价/固定成本：渠道定价（变量）显示渠道模板下拉 + 并排单选「产品重量 / 产品包装后重量」，选中项下方显示对应公式：选「产品重量」为「产品重量 * 渠道单价 + 挂号费」；选「产品包装后重量」为「(产品重量 + 数值) * 渠道单价 + 挂号费」，其中数值为计数器、默认 0.02；固定成本（常量）只显示金额输入（币种RMB），不显示下拉。采购成本与国际物流成本两行的「变量/常量」列显示文字「变量/常量」。另有独立分区「自定义成本」（位于「其他」与「定价公式配置」之间）：表头同 成本类型/变量/常量/公式/汇率转换成USD，无数据时显示「暂无自定义成本」；表格下方「+ 新增成本类型」追加一行自定义成本：红色圆形移除按钮 + 成本类型输入框 + 类型「常量」+ 公式下拉 固定成本（金额 + 币种 USD/RMB）/ 百分比（小数），固定成本且币种为 RMB 时显示实时/固定汇率，其余情况汇率列显示「—」。
    3. 活动折扣：店铺折扣（常量0.5）、平台活动折扣损耗（常量0.01）。
    4. 费率配置：平台佣金率0.05、平台提现手续费率0.01、利润率0.4。
    5. 其他：买家运费（常量5.00）。
    6. 定价公式配置：上新价 = 公式输入框；下方蓝色字段标签点击插入 #字段#；提示「公式只能包含上面勾选的字段，即下面的蓝色字段」。
  • 联动：取消勾选任一成本/折扣/费率/其他项 → 对应表格行与蓝色字段标签同步隐藏。
  • 底部：直接提交（校验后入表并关闭）、预览提交（弹出公式与配置摘要小窗）、取消。

页面 3：店铺模板配置 #page=store-template

  • 筛选：店铺名称下拉 + 运费模版输入；搜索/重置；无新增按钮。
  • 表格：店铺名称、店铺分组、运费模版（行内下拉）、售后服务模版（行内下拉）、操作人、操作时间；4 条线上数据。
  • 交互：行内下拉选择即更新该行并把操作人/操作时间置为当前（提示「已保存」）；搜索按店铺名称与运费模版过滤。

页面 4：批量修改实际收入弹窗 #page=batch-income

独立弹窗页：不还原宿主页面，整页为白底 + rgba(0,0,0,0.28) 灰遮罩，弹窗（600px）在视口垂直居中且内容完整可见（限高 + 面板内滚动）。进入页面即自动弹出；关闭后页面中央保留一个「批量修改实际收入」按钮用于重新打开。

  1. 分区一「请输入数值」：单选 替换/加/减/乘/除/清空/价格模板（默认替换，选中蓝 #2881FF）。选前五项（除清空外）时为通栏数值输入框；选「清空」时输入框禁用；选「价格模板」（末项）时输入框替换为通栏下拉「请选择价格模板」，单选自本渠道定价模版（测试模版33、LAK-美国标准专线（普＋特）-HP、燕文精品追踪--普货、测试模版3、测试模版2、测试渠道），选择后回填并收起，下拉展开不被分区或弹窗裁切。
  2. 分区二「颜色」：表头带全选勾选框，下方两条 SKU（F113-S Black / Purple，含 ☆ 销量与起订量文案）；表头勾选框可整组勾选/取消。
  3. 分区三「尺码」：同结构，一条 195*90*35mm。
  4. 每个分区 = 浅灰表头（--n1）+ 描边圆角卡片；底部按钮居中：取消（白底橙描边橙字）+ 确认修改（橙色主按钮），两者均关闭弹窗。

不做

  • 操作列（已按批注移除）、真实接口、分页翻页逻辑；批量修改实际收入弹窗的确认提交与数值运算逻辑。
