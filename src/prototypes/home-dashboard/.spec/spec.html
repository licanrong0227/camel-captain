首页驾驶舱（店铺 + 广告）

首页作为一级驾驶舱，只保留核心指标；店铺经营与广告的详细指标下沉到二级页面（店铺看板）； 底部两张排行榜卡（店铺榜 / 商品榜）首屏各 5 条，完整榜单通过弹窗查看。数据为本地确定性 mock，不接真实接口。

当前方案

  • 原型意图：把店铺经营数据与广告数据融合进首页，替代单独的数据看板页面，用于评审新驾驶舱方案。
  • 页面路由：#page=home（首页）、#page=store-detail（店铺看板）；顶部导航「报表 > 店铺 > 店铺看板」同样进入二级页（默认成交页签）。
  • 标准视口：桌面端 1440×1000；首页首屏完整呈现，二级页允许上下滚动。
  • 视觉基线：沿用首页暖橙渐变、白色毛玻璃卡片、14px 圆角与 --hd-* 变量；二级页沿用同一套 token。
  • 数据截止：2026-10-31；金额均为 USD。

页面与模块

首页（一级）

  • 首排 5 张指标卡：当日销售额、当日订单量、商品销量、广告消耗、广告投产比；均与昨日对比。
  • 异常区共 5 张卡：异常订单、异常发货、异常上网、异常物流（行为不变）+ 新增「平台处罚」；公告栏、推广轮播、联系我们保持原行为。卡片不展示图标，按「标题 + 数量」「说明 + 操作」两行排布，列宽与上方指标卡一致（同一五列网格）；平台处罚卡按天统计处罚记录总数（含处罚中与已解除），单位「条」，点击卡片打开处罚明细弹窗，卡片不设「设置」入口。≤1400 时与指标卡同步降为 3 列，≤900 单列。
  • 首页与店铺看板页头右侧均提供「手动同步」按钮与最近一次同步完成时间；点击后按钮显示同步中并禁用，约 0.9 秒后恢复，时间更新为「刚刚」，两页共享同一同步时间。
  • 数据同步逻辑：每天定时同步一次、登录时后台自动同步一次、手动点击同步一次；任一方式完成后都刷新「最近同步」时间。同步范围只包含能通过接口即时拿到的统计数据，不同步商品和订单数据。
  • 经营趋势：两个统计维度「店铺销售」（销售额左轴 + 销量右轴）与「广告投放」（广告消耗 + 广告 GMV 共用美元左轴，广告投产比用右轴 x 刻度）；周期「近1月 / 近2月 / 近3月 / 近6月」；GMV 口径开关与剔除设置。筛选条件与标题同一行，卡片右侧另提供店铺筛选（与店铺看板同款的 Element UI 风格级联多选：可按分组勾选、可搜索店铺，默认未选择即统计全部店铺），仅作用于趋势图；图例位于图表上方居中且可点击显隐对应曲线；趋势卡不设跳转链接。
  • 底部两张排行榜卡：①「店铺 TOP5 排行榜」按销售额 / 浏览量 / 等级三个维度页签切换，每个维度首屏 5 条，右上切周期（等级无周期）并提供「查看完整榜单」，弹窗内同样可切换 3 个维度；销售额 / 浏览量 / 等级三个维度的店铺行均以两行展示店铺名与别称；首页卡片中销售额 / 浏览量行不再展示经营类目，按「店铺 / 售出件数 / 成交单数 / 销售额」「店铺 / 访客 / UV 价值 / 浏览量」四列等宽均分；等级行保留经营类目，按「店铺 / 经营类目 / 等级 / 能力分」四列等宽均分，经营类目只取第一级，多个时显示首个类目 + 「等 N 类」、悬停查看全部；完整榜单弹窗中销售额 / 浏览量不展示经营类目，等级保留，类目展示规则与首页一致；并按维度同步展示售出件数、成交单数或访客数、UV 价值列；②「商品销售 TOP5 排行榜」支持销量 / 销售额 / 订单量维度切换，首屏 5 条，商品行在商品信息与数值之间展示所属店铺（店铺名 + 别称两行），商品名称过长时单行省略并以…收尾，与店铺列保留间距，「查看Top100榜单」弹窗固定前 100 条、不设分页，商品之后依次展示「店铺」与「出单 SKU 数量」，店铺列同样两行展示店铺名与别称，点击 SKU 数量打开 SKU 明细弹窗。两个弹窗的维度页签行右侧放周期筛选，标题行只保留标题、条数与关闭按钮。

店铺看板（二级）

  • 筛选条：店铺（Element UI 风格级联多选，先选分组再勾选店铺；默认未选择即统计全部店铺，面板不预勾选；勾选哪些店铺就只统计哪些，清空选择恢复全部）、时间（近1/7/30/60/90天 + 自定义，≤180天）、重置。国家下拉放在页签行右侧，仅成交 / 下单 / 流量 / 潜在页签显示，切到广告页签时隐藏；已选国家保留，切回经营页签继续生效。
  • 经营类页签使用平台原始经营数据，不提供 GMV 剔除；广告页签保留剔除数据能力（与首页趋势一致）。
  • 5 个页签：成交 7 / 下单 4 / 流量 4 / 潜在 3 / 广告 5；页签角标显示当前展示的指标卡数量。
  • 指标卡自定义：页签行中紧接页签的「自定义指标卡」打开设置弹窗，已展示指标可点红色描边圆形「−」移除、用上下箭头调整顺序；已关闭指标在文字前用橙色圆形「+」重新添加；修改即时生效。每个页签至少保留 1 张指标卡，最后一张的移除按钮置灰禁用；支持「恢复默认」。
  • 广告页签：沿用页面店铺与时间筛选（广告类型固定全部，广告无国家维度）；切到广告页签时，页签行右侧显示「剔除数据 / 原始数据」与「剔除设置」，切换口径只影响整店 GMV 与广告 GMV 占比；上方展示广告消耗 / 广告 GMV / 整店 GMV / 广告 GMV 占比 / 投产比 5 张卡（不再提供广告订单数、点击量；不带环比，宽度与其他页签指标卡一致，点击切换下方趋势，趋势指标不单设页签）；广告页签不显示「广告趋势」标题，趋势图紧接指标卡；下方复用广告明细四视图：店铺 / 商品 / 计划 / 成单词。店铺视图的店铺列与经营页签一致（名称 + 别名 + 数据不足标记），不展示「广告消耗环比」列，并在店铺名后显示该店广告趋势缩略图（仅跟随当前选中指标展示，不单独响应点击）；商品视图字段与店铺视图一致（商品 / 趋势 / 广告消耗 / 广告 GMV / 商品 GMV / 广告 GMV 占比 / 投产比），商品列置于首列，原流量、转化等明细指标收进商品广告抽屉；计划视图与店铺/商品视图同款交互，字段为 计划 / 趋势 / 广告消耗 / 广告 GMV / 广告订单数 / 点击量 / 投产比（计划维度没有商品成交额，故不含商品 GMV 与占比）；成单词视图同为行内缩略图 + 整行开抽屉，缩略图只画成单 GMV，字段为 成单词 / 趋势 / 成单 GMV / 订单数 / 涉及商品数 / 最近成单日 / 来源广告（订单报表无消耗/点击，不提供广告指标）；四张视图统一为 7 列固定列宽（主体列 280px、趋势列 120px、其余 5 列各 190px），切换页签时表头位置不跳动；页签行右侧按视图提供独立查询条件——店铺视图无查询条件；商品 / 计划 / 成单词视图可筛广告类型（全部 / 手动 / 商品自动 / 全店自动），并分别支持商品名称/ID、计划/广告组、成单词关键字搜索；各视图条件独立记忆，过滤同时作用于表格、趋势缩略图、合计与抽屉，当前视图角标显示过滤后数量，无匹配时显示「当前筛选没有符合条件的数据」；支持排序、分页、合计行，点击行打开对应抽屉。
  • 当前页签指标卡 + 趋势图；指标卡标题用小号浅色文字，并带 ? 悬停说明指标口径（页面卡片与店铺趋势弹窗一致）。店铺对比表（30 家、全列排序、分页、合计行、数据不足标记）；店铺名称后新增「趋势」缩略图列，按当前选中指标绘制该店走势，点击缩略图打开店铺趋势弹窗。
  • 不展示处罚、等级、能力分。
  • 店铺经营趋势弹窗的指标卡跟随该页签的自定义配置：数量、顺序与当前选中指标均与页面一致；弹窗内切换页签时使用对应页签的配置。

弹窗与抽屉

  • 榜单弹窗：店铺 30 行；商品按商品维度展示前 100 条。
  • 剔除设置弹窗：按店铺配置订单标签、手动订单号、手动扣减金额；保存后重算。
  • 平台处罚明细弹窗：按天展示处罚记录（处罚编号 / 来源 / 处罚类型 / 处罚原因 / 处罚日期 / 到期日 / 状态），支持状态（全部 / 处罚中 / 已解除）与来源（全部 / 平台处罚 / 品牌投诉 / 其他第三方投诉）筛选；标题行展示统计日期与总条数，标题旁 ? 说明按天统计、含全部状态；无匹配时显示「暂无匹配的处罚记录」；右上角关闭、点击遮罩与 Esc 均可关闭。
  • 商品广告抽屉：从右侧滑出（约 0.26s），遮罩同步淡入；关闭时抽屉滑回右侧、遮罩淡出（约 0.22s）后再移除；带半透明遮罩，遮罩挡住页面内容不可点击，点击遮罩、关闭按钮或 Esc 均可关闭；顶部指标卡跟随广告页签的自定义配置（数量、顺序一致，整店 GMV 换成商品 GMV），只有这些卡参与趋势，点击切换下方单指标走势；其下保留流量（曝光量 / 点击量 / 点击率 / 点击单价）与转化（订单数 / 转化率 / 单均花费）两组静态指标卡，仅展示不参与趋势；最后为计划拆分（消耗 / 订单 / GMV / 投产比列均支持点表头切换升降序，默认消耗降序，空值排末尾）与 Top 6 成单词。
  • 店铺广告抽屉：与商品广告抽屉结构一致，数据换成整店口径——顶部 5 张卡（广告消耗 / 广告 GMV / 整店 GMV / 广告 GMV 占比 / 投产比）跟随广告页签指标卡配置，点卡切换下方单指标走势；其下流量、转化静态指标卡；计划拆分与带单成单词按整店汇总。
  • 计划广告抽屉：顶部 5 张卡（广告消耗 / 广告 GMV / 广告订单数 / 点击量 / 投产比）均由广告商品报表出数，点卡切换单指标走势；其下流量、转化静态卡；明细表为「按商品拆分」（消耗 / 订单 / GMV / 投产比，列可排序），商品列展示主图、商品名称与「itemCode · 所属店铺」，成单词按计划名归属（订单接口无广告组维度）。
  • 成单词口径：自动广告（商品自动 / 全店自动）的成交没有搜索词，订单报表返回空 searchword；这类订单统一显示为「无搜索词（自动广告）」，与关键词成单词一起参与 Top 6 排序，避免成交单量与 GMV 丢失。
  • 成单词抽屉：4 张卡（成单 GMV / 订单数 / 涉及商品数 / 最近成单日）+ 按天成单 GMV 走势 + 订单明细列表（订单号 / 日期 / 商品 / 金额，日期倒序，区域滚动，商品列展示主图、商品名称与「itemCode · 所属店铺」）；不提供广告消耗、点击、投产比等接口不存在的指标。

指标与口径

指标口径
当日销售额 / 整店 GMV店铺成交金额之和；开启剔除数据后扣除命中订单金额与手动扣减金额。
当日订单量 / 商品销量成交订单数 / 成交件数；不因剔除数据变化。
广告消耗区间内广告消耗之和；USD。
广告 GMV广告商品维度成交额之和。
广告投产比广告 GMV / 广告消耗；分母为 0 显示「-」。
平台处罚按处罚日期按天统计当日处罚记录总数，包含处罚中（punishStatus=1）与已解除（punishStatus=2）；来源拆分为平台处罚、品牌投诉（dh.punish.brand.list.get 的 thirdType=brand）与其他第三方投诉（thirdType=other）。主表取 dh.punish.list.get（必传起止日期与分页），第三方投诉取 dh.punish.brand.list.get；两接口记录是否存在包含关系待联调确认，原型只展示合并后的记录列表，不做去重演示。文档 https://open.dhgate.com/docs/api/detail/72365c7a36db439c85f9265dcff8c65d 、 https://open.dhgate.com/docs/api/detail/c1c574147e4d4eb7a3161a0789bb5cfb 。
广告 GMV 占比店铺视图 = 广告 GMV / 整店 GMV（剔除数据后）；商品视图 = 广告 GMV / 商品 GMV；多店按合计重算，不做平均。
商品 GMV该商品在区间内的成交金额（含自然流量与广告成交），广告 GMV 不超过商品 GMV。
曝光 / 点击 / 点击率 / 点击单价点击率 = 点击量 / 曝光量；点击单价 = 广告消耗 / 点击量。
转化率 / 单均花费 / 客单价转化率 = 订单数 / 点击量；单均花费 = 广告消耗 / 订单数；客单价 = 广告 GMV / 订单数。
店铺经营 18 项成交转化率 = 成交买家数 / 访客数；客单价 = 成交金额 / 成交买家数；UV 价值 = 成交金额 / 访客数；成交买家占比按买家数加权汇总。
经营类目（catePubName）取卖家经营类目接口 dh.seller.crm.cate.list 的 sellerPubCateInfoList[].catePubName（发布类目名称），只保留第一级类目并按名称去重；展示在店铺榜与完整榜单的「经营类目」列。一个店铺有多个一级类目时，显示首个类目 + 「等 N 类」（如「箱包 等3类」），悬停查看全部；无类目显示「-」。文档 https://open.dhgate.com/docs/api/detail/4a2388915b7e44a7b5db0042dbf44f18 。
访客数 / UV 价值区间内该店访客数之和；UV 价值 = 成交金额 / 访客数，分母为 0 显示「-」；使用原始经营数据，不随剔除数据变化。
售出件数 / 成交单数区间内该店成交件数 / 成交订单数，不因剔除数据变化；作为销售额榜的辅助信息展示。
商品销量 / 商品销售额 / 商品订单量按商品 itemCode 汇总；支持按销量、销售额或订单量排序取前 100；商品排行本身不做规格维度。

比率一律先合计再相除；分母为 0 显示「-」；广告与订单报表互补，成单词合计与另两视图不一致属预期。

数据与范围

  • 30 家店铺（5 家广告店），5 个分组 + 未分组；120 个广告商品，另有非广告店铺商品参与商品榜。
  • 店铺经营：180 天 × 店铺 × 日期 × 6 个国家，可加指标汇总、比率重算；新店 1960 自 2026-09-20 起有数据。
  • 广告：最近 90 天有商品 / 计划 / 广告组明细，更早历史用于首页近3月 / 近6月趋势。
  • 订单：广告订单行（含成单词）+ 无效单 / 风险单等标签订单，用于成单词与剔除数据。
  • 商品名称使用英文 listing 标题（约 100–140 字符，超出 140 字符按上限截断），用于验证榜单、表格与抽屉里的省略效果。
  • 确定性锚点：零转化商品、投产比<1 商品、无效订单、新店历史不足、一笔多商品订单、自动广告无搜索词成单（示例商品 2048176201）。
  • 平台处罚：演示数据按 2026-10-31 一天构造 4 条记录（平台处罚 2 条、品牌投诉 1 条、其他第三方投诉 1 条；处罚中 3 条、已解除 1 条）；接入接口后按天取数，统计所有状态。
  • 当前不呈现：真实接口、登录鉴权、权限差异、发布记录、合规检测、商户能力诊断明细、手机端适配。

验收对账

  • 当日销售额 = 趋势「销售额」最后一点 = 店铺经营「近1天 · 成交金额」合计（剔除口径一致时）。
  • 广告消耗卡 = 趋势「广告消耗」最后一点 = 店铺看板广告页签「全部广告店 · 近1天」广告消耗。
  • 店铺看板广告页签商品视图合计 = 广告页签 KPI；计划视图合计 = 商品视图合计；成单词 GMV 合计 = 广告 GMV。
  • 店铺销售额榜前 5 = 完整榜单前 5；商品榜前 5 = Top100 前 5（同周期、同销量/销售额/订单量维度）。
  • 商品榜按商品 itemCode 汇总，支持销量 / 销售额 / 订单量排序；商品排行本身不做规格维度，规格维度只用于「出单 SKU」弹窗。
  • 出单 SKU 数量 = SKU 弹窗「组合」维度的行数；颜色 / 尺码维度各行的销量、销售额、订单数之和 = 该商品总销量、总销售额、总订单数。
  • 切换剔除数据：GMV 类数值变化，广告消耗、广告 GMV、投产比不变。
  • 店铺看板近 60/90 天，新店显示「数据不足 N 天」；经营类页签使用原始经营数据，广告页签按当前剔除口径统计。
