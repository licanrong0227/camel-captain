首页驾驶舱（店铺 + 广告）

首页作为一级驾驶舱，只保留核心指标；店铺经营与广告的详细指标下沉到两个二级页面（广告明细、店铺报表）； 底部两张排行榜卡（店铺榜 / 商品榜）首屏各 5 条，完整榜单通过弹窗查看。数据为本地确定性 mock，不接真实接口。

当前方案

  • 原型意图：把店铺经营数据与广告数据融合进首页，替代单独的数据看板页面，用于评审新驾驶舱方案。
  • 页面路由：#page=home（首页）、#page=ad-detail（广告明细）、#page=store-detail（店铺报表）。
  • 标准视口：桌面端 1440×1000；首页首屏完整呈现，二级页允许上下滚动。
  • 视觉基线：沿用首页暖橙渐变、白色毛玻璃卡片、14px 圆角与 --hd-* 变量；二级页沿用同一套 token。
  • 数据截止：2026-10-31；金额均为 USD。

页面与模块

首页（一级）

  • 首排 5 张指标卡：当日销售额、当日订单量、商品销量、广告消耗、广告投产比；均与昨日对比。
  • 4 张异常卡、公告栏、推广轮播、联系我们保持原行为。
  • 经营趋势：两个统计维度「店铺销售」（销售额左轴 + 销量右轴）与「广告投放」（广告消耗 + 广告 GMV 共用美元左轴，广告投产比用右轴 x 刻度）；周期「近1月 / 近2月 / 近3月 / 近6月」；GMV 口径开关与剔除设置。筛选条件与标题同一行，图例位于图表上方居中且可点击显隐对应曲线；卡片不设广告明细 / 店铺报表跳转链接。
  • 底部两张排行榜卡：①「店铺 TOP5 排行榜」按销量 / 流量 / 等级三个维度页签切换，每个维度首屏 5 条，右上切周期（等级无周期）并提供「查看完整榜单」，弹窗内同样可切换 3 个维度；②「商品销售 TOP5 排行榜」支持销量 / 销售额 / 订单数维度切换，首屏 5 条，「查看Top100榜单」弹窗固定前 100 条、不设分页，并在商品与店铺之间展示「出单 SKU 数量」，点击打开 SKU 明细弹窗。两个弹窗的维度页签行右侧放周期筛选，标题行只保留标题、条数与关闭按钮。

广告明细（二级）

  • 标题行只放「广告明细」，不显示副标题；GMV 口径（剔除补单 / 原始数据）与剔除设置放在广告趋势卡右上角，与趋势指标页签同一行。
  • 筛选：店铺（Element UI 风格级联多选，先选分组再勾选店铺；未选时统计全部广告店铺）、广告类型、时间（近1/3/7/15/30天 + 自定义，≤31天）、重置。
  • 6 张主指标卡：广告消耗、广告 GMV、整店 GMV、广告 GMV 占比、投产比、广告订单数。
  • 6 张辅指标卡：曝光量、点击量、点击率、平均点击单价、转化率、客单价。
  • 趋势：花费 / GMV / 订单数 / 点击量 / ROAS。
  • 四视图：店铺视图、商品视图、计划视图、成单词视图。店铺视图列：店铺 / 广告消耗 / 广告 GMV / 整店 GMV / 广告 GMV 占比 / 投产比 / 广告消耗环比，默认按占比降序，带合计行；行内「查看商品」下钻为该店商品视图。
  • 商品 / 计划 / 成单词视图：支持排序、分页（默认 10 条/页）、合计行、零转化与 ROAS<1 标记；商品行下钻抽屉（按天走势、按计划拆分、带单成单词）。

店铺报表（二级）

  • 筛选：店铺（Element UI 风格级联多选，先选分组再勾选店铺；未选时统计全部店铺）、国家、时间（近1/7/30/60/90天 + 自定义，≤180天）、重置。
  • 经营类页签使用平台原始经营数据，不提供 GMV 剔除；广告页签保留剔除补单能力（与首页趋势、广告明细一致）。
  • 5 个页签：成交 7 / 下单 4 / 流量 4 / 潜在 3 / 广告 7。
  • 广告页签：沿用页面店铺与时间筛选（广告类型固定全部，广告无国家维度）；切到广告页签时，页签行右侧显示「剔除补单 / 原始数据」与「剔除设置」，切换口径只影响整店 GMV 与广告 GMV 占比；上方展示广告消耗 / 广告 GMV / 整店 GMV / 广告 GMV 占比 / 投产比 / 广告订单数 / 点击量 7 张卡（不带环比，宽度与其他页签指标卡一致，点击切换下方趋势，趋势指标不单设页签）；广告页签不显示「广告趋势」标题，趋势图紧接指标卡；下方复用广告明细四视图：店铺 / 商品 / 计划 / 成单词，店铺视图的店铺列与经营页签一致（名称 + 别名 + 数据不足标记），并在其后显示该店广告趋势缩略图（跟随当前选中指标，点击打开店铺广告趋势弹窗查看大图）；店铺列固定 280px、趋势列固定 120px，切换页签不跳动；支持排序、分页、合计行与商品下钻抽屉。
  • 当前页签指标卡 + 趋势图；指标卡标题用小号浅色文字，并带 ? 悬停说明指标口径（页面卡片与店铺趋势弹窗一致）。店铺对比表（30 家、全列排序、分页、合计行、数据不足标记）；店铺名称后新增「趋势」缩略图列，按当前选中指标绘制该店走势，点击缩略图打开店铺趋势弹窗。
  • 不展示处罚、等级、能力分。

弹窗与抽屉

  • 榜单弹窗：店铺 30 行；商品按商品维度展示前 100 条。
  • 剔除补单弹窗：按店铺配置订单标签、手动订单号、手动扣减金额；保存后重算。
  • 商品广告抽屉：4 个 KPI + 双线下钻走势 + 计划拆分 + Top 6 成单词。
  • 店铺广告趋势弹窗：单店 7 张广告指标卡（广告消耗 / 广告 GMV / 整店 GMV / 广告 GMV 占比 / 投产比 / 广告订单数 / 点击量），点卡切换下方趋势图，口径与列表上方「全部店铺」趋势一致。

指标与口径

指标口径
当日销售额 / 整店 GMV店铺成交金额之和；开启剔除补单后扣除命中订单金额与手动扣减金额。
当日订单量 / 商品销量成交订单数 / 成交件数；不因剔除补单变化。
广告消耗区间内广告花费之和；USD。
广告 GMV广告商品维度成交额之和。
广告投产比（ROAS）广告 GMV / 广告消耗；分母为 0 显示「-」。
广告 GMV 占比广告 GMV / 整店 GMV（剔除补单后）；多店按合计重算，不做平均。
曝光 / 点击 / 点击率 / 点击单价点击率 = 点击量 / 曝光量；点击单价 = 广告消耗 / 点击量。
转化率 / 单均花费 / 客单价转化率 = 订单数 / 点击量；单均花费 = 广告消耗 / 订单数；客单价 = 广告 GMV / 订单数。
店铺经营 18 项成交转化率 = 成交买家数 / 访客数；客单价 = 成交金额 / 成交买家数；UV 价值 = 成交金额 / 访客数；成交买家占比按买家数加权汇总。
商品销量 / 商品销售额 / 商品订单数按商品 itemCode 汇总；支持按销量、销售额或订单数排序取前 100；商品排行本身不做规格维度。
出单 SKU 数量 / SKU 明细商品区间销量按 SKU 权重拆分后，出单 SKU 数量 = 有销量的 SKU 数；SKU 弹窗默认按销量降序，同时展示销量、销售额、订单数三列，点表头切换排序（不设独立排序筛选）；默认「组合」维度，可单选颜色 / 尺码 / 图案维度按该规格聚合并忽略其他规格。

比率一律先合计再相除；分母为 0 显示「-」；广告与订单报表互补，成单词合计与另两视图不一致属预期。

数据与范围

  • 30 家店铺（5 家广告店），5 个分组 + 未分组；120 个广告商品，另有非广告店铺商品参与商品榜。
  • 店铺经营：180 天 × 店铺 × 日期 × 6 个国家，可加指标汇总、比率重算；新店 1960 自 2026-09-20 起有数据。
  • 广告：最近 90 天有商品 / 计划 / 广告组明细，更早历史用于首页近3月 / 近6月趋势。
  • 订单：广告订单行（含成单词）+ 补单 / 刷单等标签订单，用于成单词与剔除补单。
  • 确定性锚点：零转化商品、ROAS<1 商品、补单订单、新店历史不足、一笔多商品订单。
  • 当前不呈现：真实接口、登录鉴权、权限差异、发布记录、合规检测、商户能力诊断明细、手机端适配。

验收对账

  • 当日销售额 = 趋势「销售额」最后一点 = 店铺经营「近1天 · 成交金额」合计（剔除口径一致时）。
  • 广告消耗卡 = 趋势「广告消耗」最后一点 = 广告明细「全部广告店 · 近1天」广告消耗。
  • 广告明细商品视图合计 = KPI；计划视图合计 = 商品视图合计；成单词 GMV 合计 = 广告 GMV。
  • 店铺销量榜前 5 = 完整榜单前 5；商品榜前 5 = Top100 前 5（同周期、同销量/销售额/订单数维度）。
  • 商品榜按商品 itemCode 汇总，支持销量 / 销售额 / 订单数排序；商品排行本身不做规格维度，规格维度只用于「出单 SKU」弹窗。
  • 出单 SKU 数量 = SKU 弹窗「组合」维度的行数；颜色 / 尺码维度各行的销量、销售额、订单数之和 = 该商品总销量、总销售额、总订单数。
  • 切换剔除补单：GMV 类数值变化，广告消耗、广告 GMV、投产比不变。
  • 店铺报表近 60/90 天，新店显示「数据不足 N 天」；经营类页签使用原始经营数据，广告页签按当前剔除口径统计。
