批量美图弹窗（转白底状态）- 主规格

当前方案

  • 原型意图：按用户提供的页面截图与样式提取信息，高保真还原「我的商品 - 骆驼队长BI」编辑产品页中「批量美图」弹窗的「转白底」Tab 界面样式
  • 范围约定：仅还原弹窗静态界面样式，不还原交互效果；弹窗背后页面不还原，使用灰色遮罩（用户已确认）
  • 独立性：与既有 batch-image 原型（加水印面板版本）互不影响，为新建独立原型

原型范围

本次呈现

  • 弹窗容器：990×636px，白底、圆角、阴影，居中显示于灰色遮罩上
  • 标题栏：「批量美图」标题 + 右上角关闭按钮
  • 左侧选项卡列：转白底（激活，橙色）/ 翻译 / 加水印 / 去水印 / 裁剪缩放，右分隔线
  • 工具行：橙色勾选「全选」+「已选 5/5 张」文案；右侧橙色「开始处理」按钮带 ? 帮助圆形图标
  • 图片网格：5 张图片卡片（图1–图5），橙色描边选中态、左上角橙色勾选圆标、底部半透明黑色信息条（尺寸 1200*/600* + 绿色「✓ 已完成」）
  • 底部按钮：「取消」（橙描边）+「确认」（橙色实心），居中于内容区

批注迭代补充的交互行为

  • 「开始处理」点击后进入处理中：按钮变红、文字「停止处理」、左侧转菊花图标、无问号；再次点击停止并恢复原状
  • 处理中：「确认」按钮禁用并显示菊花；左侧选项卡禁用且置灰
  • 「确认」按钮上方气泡「有已处理未保存的图片」：首次开始处理后出现，持续显示直到关闭弹窗
  • 「取消」/右上角「×」：弹出「提示」框引导保存（主操作「保存并退出」，次操作「退出」），点任一操作退出；提示框「×」仅关提示
  • 原型标注（AnnotationViewer）：退出保存引导、未保存图片气泡、处理中禁用选项切换 三条标注，锚点 data-annotation-id

本次不呈现

  • 任何交互逻辑（Tab 切换、勾选、处理流程、弹窗关闭）
  • 编辑产品页背景内容
  • 其他 Tab（翻译/加水印/去水印/裁剪缩放）的内容面板
